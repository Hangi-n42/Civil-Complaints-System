# 입력 묶음 전문가 역할 검수

- 검수일: 2026-09-30.
- 성격: 제3자 관점의 AI 전문가 역할 검토. 법률대리인 의견 또는 LH 현업 승인을 의미하지 않음.
- 조사 분담: 공공데이터 이용권리, LH 임대업무 문서, 공개 데이터·API 명세의 3개 역할.

## 권리 검수

- CSV·API 데이터의 개별 공개 이용조건 확인.
- 법령 조문·별표를 저작권법 제7조제1호 근거로 선정하는 것은 타당. LH 내부 사규로 확대하지 않음.
- API 가이드 발췌는 공식 연계 명세의 업무 필드·코드·짧은 설명으로 한정한 적용 판단. 가이드 전체의 명시 라이선스를 확인한 것으로 쓰지 않도록 보완.
- 기존 공고·안내·Q&A·사규의 허락 미확인을 불법으로 표현하지 않음.
- 위 내용은 `rights_review.json.final_application_review`에 기록.

## 내용 검수

- 최초 통합본14자료원·18입력파일·14보류 원본의 수량과 입력 해시 확인.
- 역사 시행령 원문에서 통합공공임대 유형 추가와 기존주택등매입 정의 범위 변경을 독립 확인.
- 2020년 역사 실행과 2026년 현재 업무 실행 분리 적절.
- 임대유형·기관 역할·식별자 차이를 구분하고 회사 내부업무 완비라고 주장하지 않는 판단 적절.
- 지적1건: 제2조가 인용한 제37조가 없어 구체적 매입대상 범위까지 판단할 근거가 부족.
- 반영: 2020-10-19 시행령 제37조 원문을 추가 확보하고 두 번째 역사 변경의 탐색 자료에 포함. **최종15자료원·19입력파일**. 제37조가 다시 인용하는 건축법 시행령의 상세 용도 정의까지 확보했다고 확대하지 않음.

## 확인하지 않은 사항

- 로컬 모델의 후보 생성 정확도와 사람의 실제 검수시간.
- PDF 전 페이지의 서비스 파싱 결과와 표 열 대응.
- LH 비공개 내부 시스템·개인정보·실시간 공고 API 응답.

이 검수는 자료선정의 이유와 경계를 확인한 작업이며, 온톨로지 구축 실행이나 승인 결과가 아님.
