# LH 자율 온톨로지 구축용 입력 묶음 v1

- 확정일: 2026-09-30.
- 선정 이유: LH 공개 데이터의 업무 필드와 실제 임대업무 법령을 연결하여 개념 발견·유형 구분·변경 검수를 준비.
- 결과: **15자료원, 19개 입력 파일 선정. 기존·보완 원본 14개는 권리 미확인 등으로 이번 입력에서 보류.** 같은 원본의 발췌·설명을 독립 자료원으로 중복 계산하지 않음.
- 범위: 공개 임대업무의 제한된 구축 파일럿. LH 내부 업무 전체의 자료 완비나 모델 품질 검증을 의미하지 않음.
- 정본 목록: [input_manifest.json](input_manifest.json). 실제 입력은 `selected_sources[].input_files`만 사용.
- 최종 설명: [자료 확정 보고서](../../../docs/70_research/company_knowledge/lh_input_bundle_2026-09-30.md).

## 입력 순서

| 실행 | 자료원 수 | 사용 방법 |
|---|---:|---|
| 현재 업무 발견 | 9 | LH 단지 CSV, API 업무 명세 3종, 관련 법령 조문 4개와 국민임대 자격 별표. 자료별 기준일 보존 |
| 대비 자료 추가 | 2 | 5년임대 목록과 분양전환임대 납부조건. 국민임대 조건으로 합치지 않고 범위 차이 검토 |
| 과거 의미 변경 | 4 | 2020-08-05 → 2020-09-08 → 2020-10-19 시행령 제2조와 2020-10-19 제37조 참조 근거. **별도 빈 기준에서 실행하며 현재 업무 자료를 함께 넣지 않음** |

- 처음부터 모든 행을 LLM 한 번에 넣는 구성이 아님. 표 헤더·자료 구조를 먼저 읽고 필요한 원문을 탐색하는 입력 범위.
- 역사 비교의 의미 변경 여부를 사람이 이미 확인했으므로 비노출 평가셋으로 부르지 않음.
- 법령 별표는 원문 PDF13쪽을 입력으로 지정. 단순 텍스트 추출본은 표의 열·조건 범위를 잃을 수 있어 정본 입력에서 제외.
- API 샘플값을 실제 공고·단지 사실로 사용하지 않음. 실제 API 응답 취득은 이번에 수행하지 않음.
- 포털 제공기관, 임대사업자, 공고 공급주체를 자동으로 같은 조직으로 취급하지 않음.

## 권리와 재현

- CSV: 개별 공공데이터포털의 `이용허락범위 제한 없음` 확인.
- API 업무 명세: 데이터셋의 명시 이용조건과 공식 연계 명세에 근거해 **필드·코드·짧은 설명만** 선정한 적용 판단. DOCX 전체 재배포 허락 확인이 아님.
- 법령: 저작권법 제7조제1호에 해당하는 조문·별표 원문. LH 사규·해설문에는 같은 근거를 적용하지 않음.
- 원본·권리 증거·발췌물 해시 기록. 원본 및 발췌 파일은 기존 `data/knowledge/raw/` Git 제외 정책 유지.
- 원본을 보관했다는 사실은 입력 허용을 뜻하지 않음. **raw 폴더 전체를 자동 수집하지 않음.** 보고서·권리 검토·평가 메모는 생성 입력에서 제외.
- 기존 `pilot_v1/sources.json`과 운영DB 자료는 유지. 아래 읽기 전용 API가 이 목록을 입력 범위로 사용.

검토 기록: [권리](rights_review.json), [LH 업무 문서](content_review.json), [공개 데이터·명세](open_data_review.json), [법령](legal_review.json).

## 자율 탐색 입력 도구 연결

- 구현: `app/knowledge/discovery_inputs.py`, 기존 `/api/v1/knowledge` 라우터 확장. `KNOWLEDGE_ENABLED=true`인 백엔드에서 사용.
- `GET /api/v1/knowledge/discovery/sources`: 선택 범위의 파일 ID·출처·권리·버전·해시 조회.
- `GET /api/v1/knowledge/discovery/read?file_id=public_housing_act_art2:0&offset=0&limit=20`: 원문 블록과 위치 조회. `next_offset`으로 다음 부분 읽기.
- `GET /api/v1/knowledge/discovery/search?q=국민임대&limit=20`: 선택 범위 안에서 키워드 검색. 반환된 `file_id`, `block_index`로 주변 원문 읽기.
- 공통 인자: `scope=current_discovery` 기본 11파일, `contrast_extension` 현재 자료 포함 15파일, `historical_change` 단계 0/1/2별 과거 자료. 역사 자료는 `step`까지 추가된 파일만 조회·검색.
- CSV는 원본 인코딩과 열 이름·행 위치 보존. PDF는 기존 페이지·표 파서 재사용. 텍스트·명세는 줄·절·문자 위치 보존.
- 읽을 때 선정 파일의 SHA-256 확인. 보류 원본, 권리 검토 메모, 다른 폴더는 검색하지 않음.
- 추가 DB·벡터 색인·LLM 호출 없음. 현 단계는 **자율 탐색 실행기가 호출할 입력 도구 연결**이며 AI의 탐색 계획·도구 호출 반복·후보 생성 실행기는 아직 미구현. 기존 K3 실행 경로는 유지.
- 실물 확인: 19파일 첫 블록 읽기, 현재 자료 검색, 역사 단계별 검색 분리 확인. 단위 테스트 1건 및 API 정상·범위 오류 응답 확인. [확인 결과](discovery_check.json).
