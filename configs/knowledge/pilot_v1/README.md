# LH 지식 파일럿 v1 — 고정 입력과 평가 과제

이 디렉터리는 K1 중 **자료 선정과 평가 과제 12건**만 고정한다. 실행 결과, 제품 품질 보증, 실제 업무 담당자의 승인 기록이 아니다.

## 파일과 사용 순서

1. `sources.json`: 공식 URL, 원문 해시, 상대 경로, 날짜 의미, 입력 절/쪽, 권리 상태.
2. `evidence.json`: 원문 위치와 짧은 확인용 발췌. 정답 판정에는 지정 문단·표 행의 전체 조건을 읽는다. 발췌 자체를 검색 입력으로 대체하지 않는다.
3. `tasks.development.json`: 알려진 문제 유형에서 선정한 개발용 6건.
4. `tasks.new.json`: 구현 전 다른 절에서 선정한 신규 6건. 동일 자료를 이전에 조사했고 설계자·AI 검토자가 정답을 읽었으므로 블라인드/독립 검증셋이 아니다.
5. `freeze.json`: 위 파일과 로컬 원문 해시, 구성 수, 검토 상태를 고정한다. 변경 시 새 버전과 변경 사유를 남긴다.

원문은 저장소 루트 기준 `data/knowledge/pilot_v1/raw/`에 있다. 원문 전체와 긴 추출 텍스트는 Git 제외다. 다른 컴퓨터에서는 허용된 공식 취득 경로 또는 적법한 로컬 사본으로 확보 후 SHA-256이 일치해야 동일 평가를 재현할 수 있다. 같은 URL에서 다른 파일이 내려오면 기존 해시를 갱신해 통과시키지 말고 새 버전으로 기록한다. 접근 제한을 우회하지 않는다.

## 평가 계약

- 유형은 구축·변경 6건 / Local 3건 / Global 3건이다. 개발/신규 구분과 별도 축이다.
- 모델·추출 입력은 등록 원문의 **선정 범위**다. 기대답, 금지 주장, 평가 근거 목록을 생성 모델 입력에 섞지 않는다. 신규 정답으로 프롬프트를 조정하면 해당 과제를 개발용으로 재분류한다.
- 모든 핵심 기대항목과 근거 연결이 맞고 금지 오류가 없어야 해당 과제가 통과한다. 일부 성공, 충분한 근거가 있는데 답변 불가, 자료상 확인 불가는 별도로 기록한다. 기존 모델 점수를 정답으로 쓰지 않는다.
- Local은 대상→사실/서류→근거/기관 등 최대 2단계 경로를 반환한다. Global은 지정 범위의 사용·제외 자료와 조건/예외를 보여준다. 그래프와 원문 비교에 동일 자료·질문·예산을 사용한다.
- `test_injections`는 평가용 후보·가상 시스템 상태다. 실제 LH 문서·승인·철회 이력으로 학습하거나 그래프에 사실 등록하지 않는다. `setup`의 활성화 역시 계획상 fixture이고 인간 승인이 완료됐다는 뜻이 아니다.
- DEV-05는 입력 누락 및 미검토/현행 미확인 자료의 coverage 고지를 확인한다. 실제 토큰 한도 처리 성능이나 검색 도중 철회·롤백 기능 전체를 검증하는 과제가 아니다.
- 구축 과제에서는 후보 개념/관계, 개체·사실, 근거, 조건·시점을 출력하여 기대항목과 대조한다. 온톨로지 명칭을 정답으로 미리 강제하지 않는다.
- 실측 시 과제별 결과/오류, 실제 호출 수·처리 시간·검토 시간을 기록한다. B0/B1/B2 측정 구간과 최소 API 계약은 후속 K1 작업이다. 이번 작업에서 평가 실행은 하지 않았다.

## 경계

- CSV 외 개별 자료의 운영 사용·재배포 이용허락은 미확인이다. 이번 선정은 로컬 원문 대조를 위한 제한된 파일럿 입력 선정이며 공개 배포 허가를 뜻하지 않는다.
- 원공고 PDF 미확보로 첫 정정 전 대기 예비자 수는 정답으로 만들지 않았다.
- 안내 개정일, 2015 시행세칙 현행성, 실시간 공실과 세대수 차이 원인은 확인되지 않았다.
- 실제 산업계·법률 전문가의 확인은 미완료다. AI 전문가 페르소나 검토를 사람의 검수나 실제 효용 검증으로 표시하지 않는다.
