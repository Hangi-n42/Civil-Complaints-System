# 1127번 실제 민원 변경안 대응표

- 대상: 2026-09-04 도봉구 공개 민원. 2025년 보건소 정차 변경과 별도 사건.
- 목적: 시민의 경유 요청을 실제 정류장 ID에 연결하고, 계산 가능한 구간과 담당자가 정해야 할 구간 구분.
- 산출물: [전체 대응 JSON](bus_change_proposal.json), [정류장 후보 좌표 46개](bus_candidate_points.json).
- 원본: `data/knowledge/raw/demo_complaints_20260929/`. 시민 원문과 첨부 지도 4장을 직접 열람하고 2026-09-02 정류장·노선 XLSX 대조.
- 결과: 현행 정차 60개, 경유 대상 묶음 13개, 실제 정류장 후보 46개, 부분 분석 경로 4개 정리. **시민 자료만으로 변경 후 전체 정차 순서를 하나로 확정할 수 없음.**
- 여기의 좌표는 정류장 좌표. 학교·아파트·관공서의 출입구 좌표로 사용하지 않음.

## 5. 대체·참고 노선과 확인된 차이

- 기본1127 `100100143`, 주민이 예시로 언급한1126 `100100142`.
- 경로 참고:1119 `100100137`,1120 `100100138`,1138 `100100153`,도봉01 `109900001`,노원14 `109900011`,노원15 `109900010`.
- 기관 답변의 도봉06 `109900003`. 노선 변경을 검토 중이라는 답변이지 변경 완료 근거가 아님.
- 시민의 대체노선 주장 중107 `100100012`,140 `100100019`,141 `100100020`,142 `100100021`,150 `100100029`,160 `100100033`은 현 파일에서 존재 확인.
- 36·118은 현 파일에서 0행. 실제 노선이 없다는 결론이 아니라 해당 파일에서 연결하지 못한 상태.
- **1126의 현행 66개 정차에는 창동고·창동역이 없음.** 민원의 ‘1126번 사례’가 이 구간을 가리킨다는 주장은 현행 자료로 확인되지 않음. 다른 노선번호로 임의 수정하지 않음.
- 대체노선 존재만으로 동일 목적지·방향·배차를 대체한다고 판단하지 않음.

## 6. 다음 처리

1. 신규 승차 후보와 목적지별 접근 차이는 부분안 단위로 계산. 기존 주민 불편을 평가하려면 삭제 후보 정차와 같은 목적지를 잇는 대체 연결도 함께 확인.
2. 전체 노선 비교 전 남측 순환 방향, 창동역 재방문, U턴 지점과 중간 정차 선택을 분석안에 명시. 현재 자료로 확정하지 못한 부분은 담당자 편집 대상으로 제공.
3. 영향 결과는 거리·직통 연결·기존 이용 규모까지 자료별로 구분. 운행시간·배차·추가 예산·민원 확률을 본 대응표에서 생성하지 않음.

- 이번 작업은 실제 민원을 계산 입력으로 구체화하는 준비 작업. 시스템 반입, 새 노선 운행 검증, 영향 수치 산출은 수행하지 않음.

- JSON의 `fixed_reference_segments`에 아래 8개를 기준일의 실제 순서로 고정. 새1127의 승인 정차 목록이라는 뜻은 아님.

- R3:도봉01 17~18순번 `10305→10231`.
