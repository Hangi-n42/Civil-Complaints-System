# 버스 영향 시연 및 LH 범위 확정 자료

- 후속 범위 정정: 전체 노선 비교를 요구하지 않음. 변경과 연결된 관계·대상의 핵심 변화를 보여주는 데 집중. [공식 명세·원천 자료 모음](../bus_ontology_sources_20260929/README.md)에 후속 수집물 정리. 현재는 온톨로지 구축 없이 자료 보관만 수행.

- 기준: 2026-09-29 자료 준비 작업. 서비스 반입·화면 구현·전후 영향 계산 완료를 뜻하지 않음.
- 목적: 실제 1127 민원의 요청을 정류장에 대응하고 보행망·대체 후보·승하차 기록을 연결. LH는 공개 운영 원장 확보 결과에 따라 시연 범위 명시.

## 버스 준비 결과

| 항목 | 파일 | 상태 |
|---|---|---|
| 실제 민원과 지도 대응 | `bus_change_proposal.json`, `bus_change_proposal.md` | 현행 60개 정차 분류, 부분 분석안 4개, 실제 기존 운행 참고 구간 8개 |
| 변경 후보 좌표 | `bus_candidate_points.json` | 실제 정류장 46개. 시설 출입구 좌표와 구분 |
| 신규 원문 출처 | `sources.json` | 2026년 8월 승하차 CSV, 강북·노원 보행망 확보 및 해시 |
| 승하차·노선 연결 | `ridership_summary.json` | 1127 현행 60/60 정확 연결, 변경 후보 46/46에 기존 경유 노선 이용 기록 존재 |
| 보행망 보완 | `walk_summary.json`, `walking_sources.json` | 3구 병합과 좁은 끝점 조회 결과. 접속 후보를 실제 보행 접속으로 확정하지 않음 |

- **전체 변경 후 정차 목록은 미확정:** 남측 순환 방향과 창동역 방문·U턴·정차 위치를 원문이 유일하게 정하지 않음. 확인된 ID·기존 순서와 신규 연결 가정을 분리. 부분안을 합쳐 승인된 전체 노선으로 표시하지 않음.
- 신규 승차 후보의 승하차는 **그 정류장을 현재 경유하는 기존 노선의 기록**. 변경 후 1127 수요를 관측한 값이 아님.
- 현행 1127의 8월 승차 118,363건·하차 116,655건은 월간 교통카드 집계. 고유 인원이나 피해 인원으로 해석하지 않음.
- 현행과 물리적 정류장을 공유하는 다른 노선 37개, 정차 관계 157개 확보. 이 관계는 정류장 원장에 157/157 연결. 방향·목적지·시간 조건 전에는 대체 가능하다고 판정하지 않음.
- 후보 주변까지 확장한 40개 노선·2,986개 정차의 이용 자료는 2,738개 단일 대응, 78개 중복 미해결, 170개 미연결. 미확인 값을 0으로 채우지 않음.
- 일부 노선이 같은 정류장을 반복 경유하므로 원본 정차 순번 보존. 승하차 원본의 정차 순번으로 유일하게 대응할 때만 반복 정차 구분.
- 8월 이용 자료와 9월 2일 노선, 2020년 기준 보행망의 기준시점은 각각 보존.

## 재생성

프로젝트의 기존 Python 환경과 설치된 `openpyxl` 사용. 새 패키지 없음. 저장된 원본에서 오프라인으로 재생성:

```sh
python scripts/prepare_bus_demo_ridership.py
python scripts/prepare_bus_demo_walk.py
```

- 다운로드 URL·POST 인자는 `sources.json`, 끝점별 조회 인자는 `walking_sources.json`에 기록.
- 원본: `data/knowledge/raw/demo_preparation_20260929/` 및 기존 자료 폴더.
- 파생 테이블: `data/processed/knowledge_demo_preparation_20260929/`. 기존 Git 제외 경로 사용.
- `1127_current_with_ridership.csv`: 현행 60개 정차와 월간 이용량.
- `removal_candidates_current_usage.csv`: 수유 진입 제외 후보 5개 정차의 기존 이용 기록. 피해 인원이나 변경 효과가 아님.
- `route_stops_with_ridership.csv`: 후보 노선의 순서·정류장·월간 이용량·미연결 상태.
- `shared_stop_alternative_candidates.csv`: 현행 1127과 정류장을 공유하는 다른 노선의 정차 관계.
- `proposal_stop_ridership_candidates.csv`: 변경 후보 정류장의 기존 경유 노선과 이용량.
- `selected_hourly_ridership.csv`: 선택 범위의 시간대별 원본 행. 다른 테이블과 합산하지 않음.
- `alternative_routes.json`: 후보 노선별 ID와 공유 정류장.
- `walk_network.json`: 병합 보행망과 미해결 링크.
- `stop_attachment_candidates.json`: 정류장별 보행 접속 후보. 직선 근접값이며 보행거리 아님.

## LH 시연 범위

- [운영 원장 확보 가능성 조사](../../../docs/70_research/company_knowledge/lh_operational_data_availability_2026-09-29.md)에서 공개 공고·공가 집계와 인증이 필요한 계약·순위 조회를 구분.
- 현재 공개 확보물로 동호·계약·배정·대기·수선을 연결한 운영 원장을 구성하지 못함.
- **현재 범위: 공고·조건·근거 변경 → 연결된 업무 지식·안내·답변의 재검토 대상 확인.**
- 동호 변경 결정문은 당시 판단의 근거 재현 자료. 실제 배정·피해 가구·수선비 영향은 동일 시점의 가명 운영 원장 확보 후 확장.
- 기존 양산 공고를 제주·하남·울산의 다른 시점 민원에 적용하지 않음.
