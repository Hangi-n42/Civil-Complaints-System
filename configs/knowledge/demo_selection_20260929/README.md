# 두 활용 시연의 선정 자료

- 선정일: 2026-09-29
- 선정 보고서: [민원 및 버스 자료 조사](../../../docs/70_research/company_knowledge/demo_data_selection_2026-09-29.md)
- 민원 우선안: LH 국민임대 복합 문의. 공식자료를 재구성한 시연 입력이며 실제 접수 원문 아님.
- 버스 우선안: 서울 도봉보건소 1127번의 승차 정류장 10118 → 10011 변경.
- 상태: 자료 확보·선정 완료. 시스템에 반입하거나 활성화한 데이터 묶음은 아님.

## 파일

- `sources.json`: 신규 원문 24개와 재사용 LH 자료 10개의 출처·경로·해시·기준일·확인 결과.
- `data/knowledge/raw/demo_selection_20260929/`: 신규 원문 24개 약 18.7MB. 기존 Git 제외 경로.
- 같은 원문 폴더의 `1127_before.json`, `1127_after.json`, `inspection.json`: XLSX·보행 JSON에서 추출한 조사용 파생 자료. 원본 24개 수에는 포함하지 않음.
- `data/knowledge/pilot_v1/raw/`: 재사용 LH 원문. 이번 작업에서 복사하거나 덮어쓰지 않음.

## 사용 방식

- `source_url`, `request_method`, `request_parameters`는 실제 다운로드 방식. 서울 XLSX와 보행망 JSON은 공식 다운로드 폼의 POST 요청 사용.
- 사람이 자료를 찾을 때는 `landing_url` 사용. 원문 재다운로드 시 파일명·자료 기준일과 해시를 확인.
- `saved_at`은 이번 로컬 파일 저장 시각이며 원자료 작성·갱신 시각이 아님. 기준일은 `reference_date` 및 선정 보고서 참조.
- 원문 자체를 Git으로 배포하지 않음. 출처별 이용 조건은 `rights`에 기록.

## 반입 전 필요한 최소 작업

1. 민원 요구별 원문 위치와 공고 적용 범위 고정. 청약통장 재사용을 입주 자격 확정과 혼동하지 않음.
2. 대표 출입구와 정류장 승차 지점의 보행망 연결 위치 확인. 기존 두 정류장 ID를 동일 개체로 합치지 않음.
3. 보행망의 2020년 기준과 노선 파일의 2025년 기준을 표시. 동일 보행망에서 두 위치를 비교하는 시연으로 사용하며 완전한 과거 현장 복원으로 표시하지 않음.

- 요청 간 캐시·새 수집 프레임워크·평가 플랫폼은 추가하지 않음.
- 기존 고정 12과제 및 정답을 변경하지 않음.
