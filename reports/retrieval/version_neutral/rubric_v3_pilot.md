# 루브릭 v3 / v3.1 파일럿 실증 (24쌍, 2채점자)

> 두 차례 독립 AI 검증으로 확정한 루브릭을 실제 (쿼리, 후보) 24쌍에 적용해 자기
> 일관성과 기존 정답지 대비 타당성을 실증하고, 발견된 약점을 v3.1로 보강·재측정한다.
> 채점 LLM = Claude(Max), 채점자 A=메인 / B=독립 서브에이전트(existing_label 미공개).

## 설정

- 기존 qrels_final 에서 라벨 0/1/2 각 8쌍, 쿼리 다양성 확보. 원천 텍스트(질문+상담사 답변) 포함.

## 1. v3 자기 일관성 (A vs B, 종합 점수)

| 구간 | 정확 일치 |
|---|---|
| label 0 쌍 (8) | 8/8 |
| label 1 쌍 (8) | 8/8 |
| label 2 쌍 (8) | 5/8 |
| **전체** | **21/24**, ±1 이내 100% (2점차 0건) |

- **0 판정(오답 차단)은 100% 일치** — 가장 중요한 안전성 판단이 안정적.
- **불일치 3건은 전부 label2의 "1↔2" 경계**, 전부 `material_conditions=2` 판정에서 갈림(A=2, B=1).
- 2차 독립 심판이 예측한 "cap·2점 경계의 주관성"을 데이터로 입증.

## 2. v3.1 보강 + 재측정 — 경계 흔들림 해소

**보강**: `material_conditions=2`를 "대상·규모·기간·시점·관할이 *명백히 동일*할 때만, 하나라도 다르면 1"로 조임(2점은 '그대로 인용 가능'이라 보수적으로).

**흔들렸던 3건 재채점 결과:**

| 쌍 | v3 (A/B) | v3.1 (A/B) | 비고 |
|---|---|---|---|
| Q-0005 간접흡연 | 2 / 1 | **0 / 0** | material=1 + generic_boilerplate_only·outdated_or_wrong_jurisdiction(안양↔서울 관할) 발동 → 안전성 강화 |
| Q-0006 창업자금 | 2 / 1 | **1 / 1** | 일반 소상공인 vs 청년 한정사업(시점·대상 다름) → material=1 |
| Q-0009 성능점검 | 2 / 1 | **1 / 1** | 중급 vs 대형 건물(규모 다름) → material=1 |

→ **3건 전부 채점자 간 수렴. 자기 일관성 21/24 → 24/24(100%).** v3.1의 material 강화가 1↔2 경계의 흔들림을 제거함을 확인.

## 3. v3 vs 기존 LLM 정답지 — 대부분 더 엄격하게 교정 (안전성 방향)

| 변화 | 건수 | 대표 사례 | 메커니즘 |
|---|---|---|---|
| 1 → 0 | 4 | 지게차 적성검사 ↔ 외벽패널 면허 / 보람일자리 ↔ 치매 위치추적기 / 흡연 의자철거 ↔ 쓰레기 종합건의 / 성능점검 기준일 ↔ 담당부서 전화연결 | issue=0(키워드만 겹침) / generic_boilerplate_only |
| 2 → 1 | 3 | 창업자금 / 성능점검 / 간접흡연(v3.1에선 0) | material<2 (대상·규모·시점 다름) |
| 1 → 2 | 1 | 유아놀이터 단체이용(같은 시설·규칙) | 실제로 거의 동일 |

기존 LLM이 "표면 유사·같은 대분류"로 후하게 준 점수를 v3가 잡아냄. `wrong_legal_framework`(건설기계관리법 vs 건설산업기본법 등)·`generic_boilerplate_only`·`outdated_or_wrong_jurisdiction` 플래그가 실제로 발동.

## 4. 결론

- v3/v3.1 **안전성 프레임이 실제 데이터에서 작동**: 위험한 표면-유사 선례를 0/1로 강등.
- **오답 차단(0 판정)은 채점자 간 완전 일치**, 1↔2 경계는 v3.1 보강으로 해소 → **24/24 일치**.
- 검증된 v3.1 루브릭으로 새 코퍼스(25,565) 전량 채점 → qrels 구축이 다음(선결: BM25 재색인·자기참조 체크). 상담사 답변 채널과 교차검증 병행.
