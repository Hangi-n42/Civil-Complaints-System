# 루브릭 v3 파일럿 실증 (24쌍, 2채점자)

> 두 차례 독립 AI 검증으로 확정한 v3 루브릭을 실제 (쿼리, 후보) 24쌍에 적용해
> 자기 일관성과 기존 정답지 대비 타당성을 실증한다. 채점 LLM = Claude(Max).

## 설정

- 기존 qrels_final 에서 라벨 0/1/2 각 8쌍, 쿼리 다양성 확보. 원천 텍스트(질문+상담사 답변) 포함.
- 채점자 A = 메인 Claude, 채점자 B = 독립 서브에이전트(같은 v3 루브릭, existing_label 미공개).

## 1. 자기 일관성 (A vs B, 종합 점수)

| 구간 | 정확 일치 |
|---|---|
| label 0 쌍 (8) | 8/8 |
| label 1 쌍 (8) | 7/8 |
| label 2 쌍 (8) | 5/8 |
| **전체** | **20/24 (83%)**, ±1 이내 100% (2점차 0건) |

- **0 판정(오답 차단)은 100% 일치** — 가장 중요한 안전성 판단이 안정적.
- **불일치 4건은 전부 "1↔2" 경계**, 전부 `material_conditions=2` 판정에서 갈림(A=2, B=1).
- 2차 독립 심판이 예측한 "cap·2점 경계의 주관성"을 데이터로 입증.

## 2. v3 vs 기존 LLM 정답지 — 대부분 더 엄격하게 교정 (안전성 방향)

| 변화 | 건수 | 대표 사례 | 메커니즘 |
|---|---|---|---|
| 1 → 0 | 4 | 지게차 적성검사 ↔ 외벽패널 면허 / 보람일자리 ↔ 치매 위치추적기 / 흡연 의자철거 ↔ 쓰레기 종합건의 / 성능점검 기준일 ↔ 담당부서 전화연결 | issue=0(키워드만 겹침) / generic_boilerplate_only |
| 2 → 1 | 3 | 창업자금 / 성능점검 기준일 / 간접흡연 | material<2 (대상·규모·시점 다름) |
| 1 → 2 | 1 | 유아놀이터 단체이용(같은 시설·규칙) | 실제로 거의 동일 |

기존 LLM이 "표면 유사·같은 대분류"로 후하게 준 점수를 v3가 잡아냄. `wrong_legal_framework`(건설기계관리법 vs 건설산업기본법 등)와 `generic_boilerplate_only` 플래그가 실제로 발동.

## 3. 발견된 약점 → 미세조정 제안

- **1↔2 경계가 흔들린다**: `material_conditions=2`(핵심 조건 동일) 판정이 채점자마다 다름. 2점은 "그대로 인용 가능"이므로 보수적이어야 한다.
  - 제안: `material_conditions=2`는 대상·규모·기간·시점이 '명백히 동일'할 때만. 조금이라도 다르면 1. 앵커 예시 1~2개 추가.
  - 효과: 2점 과대평가(고득점 오답 위험)를 줄이는 방향이라 안전성과 일치.

## 4. 결론

- v3 **안전성 프레임이 실제 데이터에서 작동**: 위험한 표면-유사 선례를 0/1로 강등.
- **오답 차단(0 판정)은 채점자 간 완전 일치** — 핵심 목적 달성.
- 남은 흔들림은 1↔2 경계뿐이며, 치명도가 낮고 미세조정 가능.
