# LH 및 버스 시연 데이터 충분성 검토

- 조사일: 2026-09-29
- 후속 작업: [보행망·승하차 연결 및 LH 범위 확정 결과](demo_data_preparation_2026-09-29.md). 아래 수치는 보완 전 기준이며 후속 결과와 구분.
- 목적: 민원 원문 확보와 관계 구축, 변경 영향 측정에 필요한 데이터 준비 수준을 구분.
- 방법: 확보 원본 직접 집계, 공식 추가 자료 확인, 주택 행정·교통 분석·평가 설계 관점의 전문가 역할 에이전트 3개 독립 검토.
- 실측 기록: [원본별 해시 및 집계](../../../configs/knowledge/demo_sufficiency_20260929/inventory.json).
- 결론: **두 사례 모두 민원 수용의 전체 영향을 판단할 데이터셋은 아직 미완성. LH는 핵심 운영 자료가 부족하고, 버스는 기초망 규모는 충분하지만 변경안과 분석 대상의 연결이 미완성.**
- 전문가 검토는 AI 역할 검토이며 실제 LH 담당자·교통기관의 승인이나 현장 검증을 뜻하지 않음.

## 1. 판정 기준과 결론

파일 수나 민원 건수 대신, 선택한 변경의 영향 경로를 구성하는 대상·관계·상태·시점과 비교 기준의 확보 여부로 판정.

| 판단 대상 | LH | 버스 |
|---|---|---|
| 기본 관계 구축 | 기존 양산 공고·조건·단지 연결은 충분 | 1127 노선·정류장·정차 순서 연결은 충분 |
| 새 민원에 맞는 업무 사실 연결 | 제주·하남 당시 사업 규정, 동호 변경 사건의 운영 원장은 부족 | 실제 변경안의 정류장 ID·방향·순서 미확정 |
| 제한된 변경 영향 측정 | 문서 변경에 따른 재검토 대상 추적 가능. 실제 입주자·배정 영향은 부족 | 공개 자료 보완 후 접근 거리·직접 연결 증감 비교 가능. 현재는 미완성 |
| 운영 전반의 실제 영향 | 타 입주자·비용·일정 영향 측정 불가 | 전체 통행시간·배차·혼잡·이용자 편익 측정 불가 |
| 새로운 민원 발생 예측 | 근거 부족 | 근거 부족 |

- 앞선 자료 선정 보고의 ‘개발 착수 가능’은 기본 연결과 시연 설계 착수에 해당. 동호 변경이나 전체 노선 개편의 영향 분석 준비 완료를 뜻하지 않음.
- 초기 LH 안내 문의에서 동호 변경으로, 2025년 버스 단일 정차 변경에서 2026년 전체 노선 변경 민원으로 범위가 확대되면서 필요한 자료도 달라짐.

## 2. LH: 단지 규모는 충분하지만 운영 관계가 없음

### 직접 확인한 자료

- 단지 현황 CSV: **6,217행, 고유 단지코드 6,217개, 11개 열**.
- 내용: 단지명·주소·임대유형·주택유형·세대수·동수·준공일·입주 지정 기간 등.
- 기존 집중 검토 범위: 양산 관련 6개 단지, 공고 3개 버전. 같은 공고의 HTML과 PDF는 별도 사건으로 세지 않음.
- 새로 확보한 사례: LH 관련 타 기관 시민 문의 2건, LH가 피신청인인 공식 결정문 1건. LH 직접 접수 신청서 원문은 미확보.

### 부족한 이유

- 단지 6,217개를 확보해도 개별 동호의 공실·점유, 계약·배정, 예비입주 순번, 수선 계획을 알 수 없음.
- 동호 변경 민원의 영향 경로인 `변경 대상 주택 → 기존 배정 → 다른 대기자 → 공급·수선 일정`을 독립적으로 구성할 수 없음.
- [국민권익위 결정문](https://www.acrc.go.kr/boardDownload.es?bid=1010&list_no=69656&seq=2)은 해당 사건의 대기자·수선 관련 판단을 이미 서술. 이를 다시 출력하면 **기록된 판단의 근거 재구성**이며 독립적인 영향 측정이 아님.
- 그래프에 대기자가 없다는 사실만으로 실제 대기자가 없다고 판정할 수 없음.
- 제주 2023년·하남 2024년 문의에 양산 2026년 공고를 적용할 수 없음. 익명화된 울산 동호 변경 사건도 양산 단지와 직접 연결할 수 없음.

### 충분해지기 위한 최소 자료

| 자료 | 필요한 연결·측정 |
|---|---|
| 같은 시점의 동호별 상태·유형·식별자 | 변경 가능한 주택과 현재 사용 상태 |
| 가명 처리한 계약·배정 원장 | 변경이 기존 계약·배정과 충돌하는지 |
| 같은 배정 범위의 대기 순번·상태 | 영향을 받는 다른 배정 대상 |
| 당시 규정과 적용 기간 | 변경 허용 조건 |
| 수선 작업·비용·기간 | 비용·일정 영향을 주장하는 경우에만 필요 |
| 실제 조치와 후속 기록 | 예측한 영향의 실현 여부를 평가하는 경우 필요 |

- 필요한 양은 전국 원장 전체가 아니라 **선정 민원과 같은 배정 범위에서 영향을 받을 수 있는 대상의 누락 없는 상태 자료**.
- [LH 공고 상세 API](https://www.data.go.kr/data/15057999/openapi.do)는 공고·단지·일정 보완 경로. 위 운영 원장의 공개 확보 가능성은 확인하지 못함. API 실제 호출은 수행하지 않음.
- 공개 자료만 사용할 경우 권장 범위: **공고·규정 변경 → 조건·일정·대상 주택유형 → 다시 검토할 안내·질문·답변**. 실제 입주자 영향과 구분해 표시.

## 3. 버스: 기초 관계 규모는 충분하지만 분석 입력이 미완성

### 직접 확인한 자료

| 자료 | 확보 규모 | 연결 상태 |
|---|---:|---|
| 서울 노선별 정차 순서 | 718개 노선, 41,688행 | 정류장 원장과 NODE_ID 일치 37,319행 |
| 서울 정류장 원장 | 고유 정류장 11,236개 | 위 정차 중 4,369행은 미매핑, 원인 미확정 |
| 1127번 선택 노선 | 정차 60행, 고유 정류장 60개 | 정류장 원장 60/60 연결 |
| 도봉 보행망 | 노드 6,464개, 링크 8,422개 | 보행 허용 링크 8,418개 |
| 보행망 누락 | 링크 123개에서 끝점 노드 미확인 | 없는 끝점 ID 98개 |

- 위 수치는 원본 데이터 집계이며 시스템에 생성된 지식그래프 크기가 아님.
- 보행망의 무방향 최대 연결요소는 6,416개 노드. 실제 보행 방향·횡단·승강장 접속이 유효하다는 증거는 아님.
- 보행망은 2020년 기준 자료라는 시점 차이가 있음. 적재 시각을 실제 도로 갱신 시각으로 해석하지 않음.
- 공개 자료 출처: [노선](https://data.seoul.go.kr/dataList/OA-1095/L/1/datasetView.do), [정류장](https://data.seoul.go.kr/dataList/OA-15067/S/1/datasetView.do), [보행망](https://data.seoul.go.kr/dataList/OA-21208/S/1/datasetView.do).

### 부족한 이유와 보완

1. **변경안 미확정:** [2026년 실제 민원](https://ceo.dobong.go.kr/bbs.asp?bmode=D&code=10000662&intPage=11&pcode=12745939)의 지도와 서술을 방향별 정류장 ID·순서로 확정해야 함. 시민 요청에서 불명확한 부분은 분석용 가정으로 분리.
2. **보행 경로 미완결:** 출발지·시설 출입구·승강장 연결과 누락 끝점을 보완해야 함. 수유 구간 등 도봉 밖 영향 범위는 인접 지역망이 추가로 필요. 누락 원인이 행정구역 경계 때문인지는 미확정.
3. **대체 이동 검토 부족:** 새로 가까워지는 시설뿐 아니라 없어진 기존 직결 경로와 대체 노선도 비교. 실제 사용할 대체 노선의 정류장 매핑부터 완결.
4. **수요 정보 미결합:** 거리 변화만으로 영향받는 이용 규모를 알 수 없음. 정류장별 승하차를 연결하면 현재 이용 규모를 함께 제시할 수 있음.
5. **운행 영향 자료 부족:** 도로별 시간·회차·차량·배차 조건 없이 전체 통행시간·혼잡·편익을 산출하지 않음.

## 4. 전문가 역할 독립 검토

| 검토 관점 | 핵심 의견 | 반영 |
|---|---|---|
| 주택 행정·온톨로지 | 단지 정보와 배정 원장은 대체 불가. 결정문 재현과 독립 영향 평가 구분 | LH 운영 영향 부족 판정, 공개 자료 대안 명시 |
| 교통 데이터·영향 분석 | 기본망 충분. 변경안·방향·보행 접속·수요가 빠지면 전체 영향 판정 불가 | 60/60 매핑과 보행 누락 별도 보고, 보완 항목 구체화 |
| 제3자 평가 설계 | 민원 입력·배경 지식·운영 상태·평가 기준을 구분. 기존 답변을 정답으로 쓰면 순환 평가 | 사후 결론 재현을 성능 증거로 사용하지 않도록 구분 |

## 5. 권장 다음 작업

1. **버스를 정량 영향 시연의 우선 대상으로 선정:** 2026년 변경안의 정차 목록을 먼저 고정하고, 영향을 받는 기존 연결까지 포함해 보행망과 시설 접속 보완.
2. **승하차 자료 결합:** 접근 거리 변화와 기존 이용 규모를 함께 제시. 필요할 때 기종점 자료를 추가해 기존 직결 연결 상실의 이용 규모 확인.
3. **LH 운영 영향은 자료 확보 조건을 먼저 해결:** 같은 범위의 가명 원장을 협력 기관에서 받을 수 있는지 확인. 확보 전에는 문서 변경 영향과 근거 검토로 범위를 명시.
4. **평가는 좁고 독립적으로 수행:** 선정 사례의 수작업 연결·계산 기준표를 만들고 기본 문서 검색과 비교. 놓친 대상·잘못된 연결·계산 일치·검토 시간을 확인. 기관 답변은 생성 입력과 분리하고 자동 정답으로 취급하지 않음.

- 민원 수를 임의로 늘리는 것보다 선정 요청에서 영향 경로가 완결되는 자료를 확보하는 것이 우선. 사례 1건의 계산 성공은 다른 사례로의 일반화 증거가 아님.
- 온톨로지의 효용은 그래프 표시 자체가 아니라 **민원 표현을 업무 대상에 연결하고 조건·시점에 맞춰 검토 대상을 누락 없이 찾는지**로 확인.
- 이번 작업은 조사·집계·검토 기록만 추가. 실제 영향값 계산, 모델 평가, 서비스 코드와 PRD 변경은 수행하지 않음.
- 현재 판정을 위해 사용자 결정이 필요한 사항 없음. LH의 실제 배정 영향을 필수 시연으로 유지하려면 운영 자료 협력 확보가 선행 조건.
