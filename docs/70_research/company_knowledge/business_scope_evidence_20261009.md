## 조사 범위 오류의 원인과 수정

누락 38개에는 메뉴·공유 항목뿐 아니라 이전등록 정의·절차·공통 서류·번호판·매매·상속 서류가 포함돼 있다. 이미 확보한 세 필수 의미만 보고 모두 무관하다고 결정하지 않는다. 누락 중 일부가 나중 호출의 문맥으로 들어간 사실도 전체 대상 조사를 대신하지 않는다.

기존 추가 읽기는 미선택 블록만 다시 읽었고, 이미 선택됐으나 조사 선언에서 빠진 블록은 재개하지 않았다. 완료 판정은 과거 범위 오류 문자열을 계속 현재 공백으로 더했다. 수정은 해당 영수증의 미조사 대상을 다시 선택하고, 같은 요구 revision·source version·parse·블록·전체 구간의 실제 후속 영수증의 유효한 조사 선언을 누적한다. 전체 대상 coverage를 충족했을 때만 과거 조사 오류의 현재 적용을 종료한다. 원래 영수증·오류·이의·의미는 삭제하지 않는다. 개별 의미 오류는 조사 coverage 오류와 별도로 남는다. 종합 입력에도 과거 오류와 함께 후속 조사 연결·현재 남은 대상·조사 오류의 현재 유효성을 전달한다. 최초 응답의 정상 선언 부분과 후속 응답의 정상 선언 부분을 같은 기준으로 누적하며, 미선언 대상은 채우지 않는다.

실제 재조사는 대상 38개, 제공 45개로 고정했다. 기존 네 조사 블록은 문맥으로 남겼다. 원래 제품 `source(previous=...)` 경로를 실행하며 모델 출력이나 입력 블록을 진단 코드에서 대체하지 않았다. 원문 1회와 필요한 경우 기존 적용성 호출 1회만 허용했고 실패 재시도는 허용하지 않았다.

UI라는 사후 확인으로 해당 응답의 실패를 성공으로 재채점하거나 ID·본문별 제외 규칙을 추가하지 않았다.

## 승인 후보의 정확 근거를 검색에 전달

기존 승인 다섯 후보는 원시 evidence가 넓은 추출 chunk를 가리켜 같은 후보들이 98개 원문 구간에 함께 연결됐다. 새 승인 스냅샷에는 현재 후보·원문·요청·모델 설정·실제 응답이 일치하는 후보 전체의 자기 출처 검수만 별도 `reviewed_claim_evidence`로 저장한다. 승인되지 않았거나 후보가 바뀌었거나 주소가 어긋나면 원래 근거로 돌아간다. 후보 원문과 원래 chunk 주소는 수정하지 않는다.

검색 투영은 실제 검수의 다중 근거를 모두 보존한다. b29 미방문 조건은 다섯 후보, b30 서류 목록은 c10/c11/c12/c46, b31 날인 조건은 c13/c46에 연결된다. 정적 그래프는 134개 노드·1,141개 간선·98개 구간에서 39개 노드·93개 간선·3개 구간으로 바뀌었다. 구간 외 후보·개념 노드의 ID와 속성, 기존 관계·개념 간선, 제외 개념 목록은 완전히 같다. 간선 감소는 원문 연결 축소이며 의미 정확도 상승을 뜻하지 않는다.

승인 그래프의 검색 임베딩에도 기존 필수 원문 문맥 구성을 적용했다. 따라서 과거 QA와 새 QA의 차이를 근거 투영 하나의 효과로 부를 수 없다. 투영의 비교는 같은 새 코드·필수 문맥·질문·다섯 후보·후처리에서 원래 chunk와 검수 근거의 두 스냅샷을 각각 한 번 질의한다. 정확히 같은 성공 요청만 기존 응답 캐시를 사용할 수 있다. 필수 의미 보완 전 검색 결과와 보완 후 결과를 따로 보존한다.

이전 스냅샷은 `cae36c470c4345859f0e5108d6002aae`, 새 비교 스냅샷은 `c5644e0b2f8042739b25c314b1a64663`이다. 같은 다섯 후보·블록·평가를 사용하고 기존 원문 DB와 스냅샷이 바뀌지 않았음을 확인했다. 새 승인은 조정 AI의 진단용 명시적 승인이고 인간 승인이 아니다. 원문 조사 실행과 별개로 기존 partial 평가를 그대로 사용하는 대조다.

실제 raw 실행은 `d1362f7f17fd47d1b795760cbbf2e738`, 검수 근거 실행은 `c9d4d019f9bd4d21ac2a20945dafd0be`다.

로컬 임베딩과 그래프 순위 계산은 두 실행에서 실제로 수행했다. LLM 필터·QA 응답 네 개만 정확한 요청 일치를 확인해 재사용했다. 필수 의미 후처리는 기존 다섯 hit의 score·passage ID를 보존하고 selection_reason만 바꿨다. 투영 전후 필터와 QA의 메시지·schema·주소맵·모델 요청 설정이 정확히 같았다. 최종 답변은 양쪽 및 직전 기준 실행과 완전히 같고, 세 의미·위임장 날인·양도증명서의 두 날인 위치·법인 대체 서류·기존 partial 한계를 유지했다. 질문과 criterion에 같은 세 의미를 반복하는 기존 표현도 그대로다.

확인한 효과는 불필요한 원문 연결 축소와 질문에 맞는 검수 구간 연결이다. 후보 선택 증가·답변 품질 상승·새 의미 판단 성공은 관찰되지 않았다. 다섯 후보가 공통 조건 b29에서 모두 검색됐으므로 개별 서류를 세밀하게 구별하는 검색 능력을 입증한 것도 아니다. 서로 다른 그래프의 PageRank score 크기를 품질 점수로 비교하지 않는다. 실행 경과 raw 12.038234초, 검수 근거 4.681492초는 정확 응답 캐시와 서비스 실행 순서가 있는 단일 로컬 기록이며 추론 속도 개선으로 일반화하지 않는다.

## 검증 및 남은 범위
