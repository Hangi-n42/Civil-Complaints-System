# 업무 지식 직접 편집과 c47 후속 경로 검증 — 2026-10-08

## 판정

Event 문장 직접 편집 API·화면·변경 이력·재검수·그래프 갱신을 연결했다. 버전 충돌·근거·역할 제한과 자동 승인 금지를 계약검사로 확인했다. 기존 저장 자료의 사본에서 실제 모델 재검수와 full 검색·답변까지 실행했다.

**기능 연결 완료와 의미 품질 성공은 다르다.** 조건을 제공한 모델 교정은 저장되지 않았으며 정상 의미도 모두 보존하지 못했다. 별도 기준 수정본은 원문 대조상 일반 구비항목과 지역 번호 의무를 유지했고 다른 118개 후보도 그대로였다. 그러나 모델의 보존 판정은 모순되어 검증이 완료되지 않았다. 기준 수정본은 저장 그래프, 검색 결과, 실제 답변 입력까지 전달됐지만 최종 답변은 수정된 구비항목·지역 번호 반납 의무를 사용하지 않았다. 전체 R05 품질은 실패다. 진단 운영자가 입력·선택했으며 실제 사람 검토나 운영 승인 결과가 아니다.

## 후속 저장 버전 → full 검색 → 실제 답변

진단용 DB 사본에서 기존 decisions 경로로 선택 가능한 19개를 선택했다. 이유에 실제 사람 검토가 아니며 보존 실패를 성공으로 세지 않는다고 기록했다. 첫 QA 시도는 limit=12가 필수 19개보다 작아 모델 호출 전에 거절됐다. 실패를 보존하고 별도 사본에서 limit=19로 실행했다.

스냅샷 `00547c250b6f44068b96715283de061c`, query run `9334d4c077504651916b064338a353b4`에서 같은 R05 질문과 기준을 사용했다. `hipporag2`, full, synthesis이며 로컬 BAAI/bge-m3 CPU를 사용했다. 검색 그래프는 노드 370개, 엣지 5,271개, passage 172개, 개념 노드 137개였고 fallback은 없었다.

c47은 passage `passage_1ac718041ac900f8a7aeb365`, score `0.008185104925589588`, selection_reason=`required_reviewed_meaning`으로 포함됐다. 따라서 **full 그래프 검색과 필수 의미 포함 경로의 전달**을 확인한 것이며 c47의 자율 순위 선정 성공이라고 할 수 없다. 실제 business_qa unit `e3097e11e61e4853b0de1c9b30167387`의 입력에 수정 문장이 포함돼 있었다.

최종 상태는 answered였지만 품질은 실패다.

- 최종 citations 7개에 c47이 없다. 답변은 기존번호판·봉인 구비항목이나 지역 번호의 선행 반납 의무를 표현하지 않는다. **수정 의미를 실제 답변에 사용한 성공은 미달**이다.
- 명지·금련산의 번호판 교부 안내로부터 번호판 변경 처리 가능을 추론했다고 limitations에 명시했다. 그러나 답변 본문은 처리 가능으로 단정했다. 한계란의 추론 고지가 본문의 근거 부족을 해소하지 않는다.
- R05 criterion은 구비서류와 처리 범위를 함께 확인하도록 요구한다. 답변은 기관 비교에 집중한다는 이유로 구비서류를 생략했다. 금련산 2~3일과 센터 제외 항목 일부가 남은 것만으로 전체 기준을 충족하지 않는다.
