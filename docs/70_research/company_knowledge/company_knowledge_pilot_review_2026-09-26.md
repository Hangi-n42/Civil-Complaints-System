# 회사 지식 파일럿 K1 자료·과제 고정 검토

- 일자: 2026-09-26
- 역할: 제3자 평가설계·데이터 provenance 심사위원 관점의 **AI 페르소나 검토**. 실제 현업 전문가 승인이나 사람이 완료한 검증이 아니다.
- 대상: `configs/knowledge/pilot_v1/sources.json`, `evidence.json`, `tasks.development.json`, `tasks.new.json`; 연결된 로컬 raw 및 staging 원문·추출 자료.
- 범위: 자료·정답 고정의 평가 가능성과 근거 일치. 제품 구현·12건 실행·성능/시간 측정은 수행하지 않았다.

## 확인 결과

- 과제 12건, 개발 6건/신규 작성 6건, 구축·갱신 6건/Local 3건/Global 3건으로 배분됐다.
- 원문 11개 파일의 SHA-256이 manifest와 일치했다. 모든 과제의 evidence ID가 존재하며 참조 근거의 source ID는 해당 과제 자료 범위 안에 있었다.
- CSV 공식 단지 6행을 물리 행 번호 및 전체 열 값과 대조했다. HTML 단지 6코드는 지정된 원문 행 구간의 값과 일치했다. 신규 HWPX 근거는 지정 XML 노드를 직접 읽어 Q5·Q7·Q8·Q12·Q13과 표지 기준월의 기대 내용과 대조했다. 신규 HTML은 해당 안내 본문·표 행을 대조했다.
- PDF 정정 날짜와 단지 표는 보존된 페이지 추출 자료와 대조했다. 이번 검토에서 모든 PDF 페이지를 별도로 재렌더링하거나 문서 전체 수치를 검산한 것은 아니다.
- 실제 원문 정정, 별도 무근거 후보 주입, Global 미검토/제외/예산 누락 fixture가 구분돼 있다. 근거 부족을 환각과 구분하면서 충분한 근거가 있는 과제의 정답 누락을 성공으로 세지 않는 규칙은 적절하다.
- 신규 6건은 기존 조사 자료의 새 절·질문이며 설계자·AI 검토자에게 노출됐다. 파일에 비블라인드·인간 현업 검토 미완료가 표시돼 있다. 독립 holdout/현업 승인으로 보고할 수 없다.
- CSV 외 개별 로컬 처리·재배포 권리는 확인되지 않은 상태로 기록돼 있다. 공개 접근 또는 로컬 선정이 이용허락 확인이라는 주장은 없다. 원문 전체 Git 제외 방침을 유지해야 한다.

## 초안에서 발견한 수정 필요 사항

### 1. DEV-05 갱신 조건의 근거 위치 오류 — 정답 고정 전 수정 필요

초안 `conditions_2`는 물리 3쪽/인쇄 6쪽의 대기 예비자·주거약자 설명이다. DEV-05-C3의 갱신 1회/2회 및 무주택 완화 갱신 조건은 이 위치가 아니라 **물리 2쪽/인쇄 3쪽 입주자격 완화 주요내용**에 있다. `conditions_1` 발췌도 소형·저가주택 설명 중간에서 끝나 예외 조건을 확인할 수 없다.

최소 수정: 같은 실제 페이지에서 소형·저가 요건, 2호/2세대 이상 제외, 소득·자산 재계약, 무주택 완화 재계약을 각각 확인할 수 있는 짧은 근거로 연결한다. 기대 문구의 ‘초과’는 원문의 **‘미충족’**으로 맞춘다. 2회 미충족 시 적격 예비입주자가 없는 조건, 공고일 전 취득 주택과 1회차/2회차 재계약 조건을 판정 항목에 남긴다. 문서의 후속 일반 갱신 설명과 긴장이 있는 부분은 자동 우선순위로 해결하지 않는다.

### 2. NEW-06 표지 기준월의 입력 범위 — 작은 scope 보완 필요

LH-QA-2026은 `corpus_scope.include`를 임대주택 Q1~Q16으로 지정했지만 NEW-06-E1은 표지의 `2026.03 기준`을 참조한다. 근거 자체는 실제 XML 노드에 존재한다.

최소 수정: 표지 기준월을 문서 메타데이터로 읽는 것을 범위에 명시한다. 임대 외 Q&A 내용까지 지식 입력에 확대할 필요는 없다.

## 적용 한계

- `as_of=null`과 고정 해시 범위는 과거/현행을 자동 판정하지 않는 평가 목적에는 사용할 수 있다. 이번 고정 과제는 특정 역사 시점의 완전한 상태 복원이나 실시간 정책 최신성 검증을 증명하지 않는다.
- 변경 영향 그래프의 모든 경로, 롤백·생성 중 상태 변경·모든 NFR이 12건으로 검증되는 것은 아니다. 이번 단계에 별도 대규모 과제를 추가할 필요는 없으며 해당 구현 단계의 대표 확인과 구분한다.
- 새 확인용 정답을 추출·검색 프롬프트나 튜닝에 사용하면 별도 확인용 자격을 유지할 수 없다. 정답 작성·검토를 위해 AI가 이미 본 사실은 기록돼 있으므로 완전한 블라인드라는 표현을 사용하지 않는다.
- 결론: 위 두 가지 좁은 수정 후 **구현 전 자료·과제 고정용으로 사용 가능**. 이는 실행 통과나 정확도 입증을 뜻하지 않는다. 아래 후속 확인에 실제 수정 여부를 별도로 기록한다.

## 후속 확인

초안 검토 완료 시점에는 위 수정 요청을 주 에이전트에 전달했다. 이 문서 작성 자체로 원문·과제 JSON을 변경하지 않았다.

### 수정 후 재확인

- `conditions_renewal`이 물리 2쪽/인쇄 3쪽의 실제 재계약 문구로 추가됐고 DEV-05-C3이 해당 근거만 참조하도록 수정된 것을 확인했다. `conditions_1`은 소형·저가 조건과 2호/2세대 이상 제외까지 포함하며, 기존 `conditions_2`는 대기 예비자 주석으로 명확히 구분되어 DEV-05 갱신 근거에서 제외됐다.
- DEV-05-C3은 ‘미충족’으로 수정됐으며 2회 미충족 시 적격 예비입주자 부재, 무주택 완화의 공고일 전 취득/1회차/2회차 조건 및 2회차 이상 일반 주석을 보존한다. 보존된 물리 2쪽/인쇄 3쪽 원문 내용과 일치한다.
- LH-QA-2026 `corpus_scope.metadata_include`가 표지 기준월과 실제 XML 노드 86을 문서 메타데이터로 명시한다. 본문 범위를 임대 외 분야까지 확장하지 않았다.
- **최종 판정: 발견한 두 수정 사항이 해소되어 현재 자료·12개 과제는 구현 전 고정 입력/판정 기준으로 사용 가능하다.** 비블라인드·인간 검토 미완료·개별 문서 권리 미확인·제품 실행 미수행이라는 한계는 그대로 유지된다. 이 판정은 해당 제한된 AI 문서 검토 결과다.
