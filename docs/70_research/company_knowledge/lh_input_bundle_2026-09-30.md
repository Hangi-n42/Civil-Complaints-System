# LH 자율 온톨로지 구축 입력 묶음 확정

- 작성일: 2026-09-30.
- 목적: 로컬 LLM이 자료를 탐색해 개념·관계 초안을 제안하고 사람이 변경사항을 검수하는 기능의 실제 입력 준비.
- 기준: 사용자 제공 「에이전트 기반 온톨로지 초안 구축」과 [이전 충분성 검토](lh_autonomous_ontology_dataset_review_2026-09-29.md).
- **결과: 사용 근거와 내용을 확인한 15자료원·19개 입력 파일을 제한 파일럿용으로 확정. LH 회사 내부 업무 전체를 재현하는 완비 자료셋은 아님.**
- 정본: [입력 명세](../../../configs/knowledge/lh_input_bundle_20260930/input_manifest.json), [사용 안내](../../../configs/knowledge/lh_input_bundle_20260930/README.md).

## 1. 왜 이 자료를 선정했는가

- 단지·임대조건 데이터로 실제 속성과 식별자를, 공개 API 명세로 필드·코드·연결 구조를, 법령으로 업무 개념·조건·예외를 제공.
- LH의 모든 문서를 무조건 모으기보다 **임대업무 개념 발견과 실제 의미 변경을 확인할 자료**에 집중.
- LH가 제공한 자료와 LH 업무에 적용되는 법령을 연결. 다른 기업 데이터셋으로 전환하지 않음.
- 법령은 LH 내부 사규나 직원의 암묵지를 대신하지 않음. 자료 출처와 역할을 구분.
- 이용허락이 확인되지 않은 문서를 허용 자료와 섞어 충분하다고 판정하지 않음.

## 2. 확정 입력

| 묶음 | 자료 | 실제 확보·선정 내용 | 활용 |
|---|---|---|---|
| 현재 업무 발견 | 전국 LH아파트 단지정보 | CSV6,217행·11열과 공식 데이터 설명 | 단지ID·동수·세대수·임대유형·기준시점 구분 |
| 현재 업무 발견 | 분양임대공고 목록 API | 원본 DOCX와 업무 필드·유형·상태 코드 발췌 | 공고ID, 유형과 상태, 상세조회 연결 |
| 현재 업무 발견 | 공고 상세 API | 원본 DOCX와 국민임대 관련 공급정보 분기 발췌 | 공고·단지·접수처·서류접수·당첨·계약 일정 구분 |
| 현재 업무 발견 | 공공임대 단지 API | 원본 DOCX·지역코드 XLSX, 업무 명세·코드 발췌 | 기관·지역·단지·면적·보증금의 의미 구분 |
| 현재 업무 발견 | 법령 조문4개와 별표1개 | 공공주택 특별법 제2조, 시행령 제2조, 시행규칙 제15조·제17조의2, 별표4 원문13쪽 | 상하위 임대유형, 국민임대·통합공공임대 차이, 자격·조건·예외 |
| 대비 자료 추가 | 5년임대 목록 | CSV70행·19열과 공식 설명 | 제공기관과 실제 임대사업자 차이 |
| 대비 자료 추가 | 분양전환임대 납부조건 | CSV576행·15열과 공식 설명 | 사업지구·블록·주택형·면적·보증금 구성 |
| 과거 의미 변경 | 시행령 제2조 3버전과 참조 조문 | 2020-08-05, 2020-09-08, 2020-10-19 제2조 및 2020-10-19 제37조 원문 | 유형 추가와 용어·정의 범위 변경 |

- 자료원15개 중 현재 업무9개, 대비2개, 역사4개. 발췌·설명 파일을 합한 실제 입력19개이며, 자료량을 부풀리기 위해 중복 계산하지 않음.
- API 실제 응답은 취득하지 않음. 공개 명세의 샘플값은 실제 공고나 단지 사실로 사용하지 않음.
- 공공임대 단지 API는 개선 제공 서비스 안내가 있어 이번에는 필드·코드 참조용. 운영 API 연결을 완료했다는 의미가 아님.
- CSV마다 기준일·인코딩·필드명을 보존. 서로 다른 시스템의 단지 식별자를 자동으로 동일시하지 않음.
- 5년임대70행 중 임대사업자 LH30행·그 외40행을 실제 확인. **LH가 제공한 데이터가 모두 LH 소유·운영 주택이라는 해석은 틀림.**
- 분양전환·5년임대 조건을 국민임대 자격이나 현재 양산공고에 적용하지 않음.

공식 자료: [단지 CSV](https://www.data.go.kr/data/15080989/fileData.do), [공고 목록 API](https://www.data.go.kr/data/15058530/openapi.do), [공고 상세 API](https://www.data.go.kr/data/15057999/openapi.do), [공공임대 단지 API](https://www.data.go.kr/data/15058476/openapi.do), [5년임대 목록](https://www.data.go.kr/data/15084922/fileData.do), [분양전환 임대조건](https://www.data.go.kr/data/15139855/fileData.do).

## 3. 실제 의미 변경 사례 확보

공공주택 특별법 시행령 제2조 원문을 시행일별로 직접 대조.

- **2020-08-05 → 2020-09-08:** `통합공공임대주택` 유형과 정의가 제1항제3호의2로 추가됨. 단순 날짜·가격 변경이 아닌 개념 유형 추가를 확인할 수 있음.
- **2020-09-08 → 2020-10-19:** `기존주택매입임대주택`이 `기존주택등매입임대주택`으로 변경되고, 매입대상이 기존주택에서 지정된 주택 또는 건축물로 확장됨. 문자열이 비슷하다고 시점과 정의 범위를 무시한 동의어 병합을 하면 안 되는 사례.
- 제3자 검수에서 지적된 참조 근거 누락을 보완하여 2020-10-19 제37조도 확보. 제2조에서 제37조를 추가 탐색해 열거된 매입대상 용도명과 조건을 확인할 수 있음. 그 조문이 다시 인용한 건축법 시행령의 상세 용도 정의는 이번 범위 밖.
- 2026년 자료와 섞으면 이미 후속 정의를 알고 시작하므로, **과거 자료만으로 별도 초기 기준과 두 번의 추가 입력을 구성**.
- 자료를 직접 읽고 확인한 개발용 사례. 모델이 변경을 정확히 발견했다는 결과나 비노출 평가 성과가 아님.

원문: [2020-08-05](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=220433&joNo=0002&joBrNo=00&docCls=jo&efYd=20200805&chrClsCd=010202), [2020-09-08](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=221449&joNo=0002&joBrNo=00&docCls=jo&efYd=20200908&chrClsCd=010202), [2020-10-19](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=220721&joNo=0002&joBrNo=00&docCls=jo&efYd=20201019&chrClsCd=010202).

## 4. 권리 판단

| 자료군 | 사용 근거 | 적용 범위 |
|---|---|---|
| 공개 CSV3종 | 개별 공공데이터포털의 이용허락범위 제한 없음 확인 | 해당 데이터와 필드 설명 |
| API 데이터3종 | 개별 서비스의 이용허락범위 제한 없음 확인 | 실제 제공 데이터의 이용조건. 이번에는 응답 미취득 |
| API 업무 명세 발췌 | 위 이용조건과 공식 연계 활용명세의 목적에 근거한 선정 판단 | 필드·코드·짧은 설명만 로컬 분석·근거 검토에 사용. 원가이드 전체의 별도 자유재배포 허락 확인 아님 |
| 법령 조문·별표 | 저작권법 제7조제1호 | 현행·역사 법령 원문. LH 내부규정·해설·사이트 디자인으로 확대하지 않음 |
| 일반 LH 문서·업무분장 | 예정 이용에 대한 명시 허락 미확인 | 이번 확정 입력에서 보류. 불법 판정 아님 |

- [저작권법 제7조](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=283335&joNo=0007&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR)와 [LH 공공데이터 이용정책](https://www.lh.or.kr/menu.es?mid=a10110010000)을 직접 확인.
- API가 공고 PDF의 URL을 제공한다고 해서 링크된 PDF 전체의 이용허락까지 확장하지 않음.
- 권리 전문 역할 에이전트가 위 적용을 독립 재검토. 데이터셋 명시 라이선스와 명세 발췌의 적용 판단을 구분하도록 보완.
- 분쟁 가능성0을 보증하거나 전체 저작물의 법률 감정을 완료했다는 의미가 아님. 원문 전체 재배포·모델 가중치 학습은 이번 선정 범위 밖.

## 5. 확보했지만 이번 입력에서 보류한 자료

- 기존 파일럿 문서10개: 공고HTML3·PDF2, 안내3, Q&A1, 2015시행세칙1. 파일을 삭제하거나 기존DB에서 비활성화하지 않음.
- 신규 LH 문서4개: 직제규정2026-06-26, 직제규정 시행세칙2026-01-20·2025-11-06, 주택임대규정2009-10-01 제정본.
- 합계14개 원본을 보류 목록에 기록. 취득·본문 확인과 사용허락 확인을 구분.

새로 확인한 내용:

- 2026 직제세칙300쪽 중 물리35~38쪽 등에 공급계획·자격검색·예비자·공가·갱신 담당 역할이 명시됨. **내부 업무관계의 내용 자료는 존재함. 현재 공백은 해당 자료의 이용권리 확인.**
- 물리5쪽 신구대조표에 울산권주거복지지사의 소속 이동이 명시됨. 이는 조직관계 사실 변경이며 온톨로지 클래스 변경으로 확대하지 않음.
- 주택임대규정은2012게시 자료이나 실제 제정·시행은2009. 이미지PDF라 자동 입력에 OCR도 필요. 현행2026업무 기준으로 채택하지 않음.
- 기관 문의를 위한 [이용범위 확인 요청 초안](../../../configs/knowledge/lh_input_bundle_20260930/permission_request_draft.md) 작성. 발송·제공신청은 하지 않음.

## 6. 이 묶음으로 할 수 있는 일과 남은 일

**입력 준비가 된 범위**

- 서로 다른 형식의 공식 자료를 탐색해 임대 개념·속성·관계 후보를 제안하는 제한 파일럿.
- 임대유형·기관 역할·단계별 날짜·면적·개수의 의미를 혼동하는지 확인할 근거 제공.
- 실제 역사 자료를 추가해 유형 추가·정의 범위 변경을 사람이 검수하는 흐름 준비.

**아직 완료되지 않은 범위**

- LH 내부 담당부서·책임·예외 절차를 포함한 회사 지식 전체. 보류 문서의 허락 또는 동등한 개방 근거 필요.
- 실제 공고 API 응답을 이용한 연결. 인증키·활용신청이 필요한 별도 단계이며 현재는 명세만 확보.
- 자율 탐색 실행, 후보 생성·사람 검수 시간·정확도 측정. 이번 작업에서는 모델을 호출하지 않음.
- PDF 별표의 표 구조를 보존하는 실제 서비스 파싱 결과. 원문13쪽과 페이지별 추출본을 확보했고 첫쪽 원문을 시각 확인했으나, 텍스트 추출만으로 열의 대응이 검증됐다고 하지 않음.

## 7. 완료 보고

- 진행 이유: 기존 LH 자료를 버리지 않고, 권리와 내용이 확인된 부분부터 실제 입력으로 고정하기 위함.
- 결과: 자료선정·권리·업무내용 전문가 역할3개로 나눠 조사하고 입력 명세에 통합. 로컬 파일과 원본·발췌 해시, 근거 위치, 사용범위 기록. 온톨로지·서비스·기존PRD·운영DB 변경 없음.
- 다음 작업: 자율 탐색 구현에 이 목록을 연결하고 제한 파일럿부터 확인. 내부 책임관계까지 확장할 때는 준비된 문의 초안으로 보류 문서 이용범위 확인.
- 사용자 결정 사항: 확정 묶음 준비에는 추가 결정 없음. **기관에 문의를 실제 발송할지는 별도 사용자 지시 필요.** 이번 작업에서 외부 연락은 수행하지 않음.
