## 최종 상태: 국소 교정 확인, 전체 CQ 의미 검증 미통과

## 남은 병목과 원인

1. **문서 간 연결의 의미 정확성.** 인용 주소가 정확해도 그 문장이 법적 포함의 모든 전제를 충족하는지는 별도 의미 판단이다. 현재 스키마·서버 검사는 구조와 근거 주소를 검증하지만 의미 충분성을 보장하지 않는다. v10은 전체 `unknown` 안에도 근거 없는 개별 `supported`가 남을 수 있음을 보여줬다. v11에서는 이 연결이 `extraction_missing`으로 바뀌어 복구 요청에 들어갔다. 원문에 없는 관계를 실제 누락으로 오판하는 병목이 남았다. 이번에는 추가 라운드 0·호출 1회로 생성되지 않았지만, 이 결과를 자동 보완 입력으로 신뢰할 수 없다.
2. **허용 원문에 없는 내용.** 외부 시행령 정의·별표의 실제 내용은 두 문서에 없으므로, 코드나 프롬프트를 보완해도 확정할 수 없다. 필요한 경우 그 원문을 승인된 입력으로 별도 고정해야 한다. `unknown`을 없애는 것이 품질 개선 목표는 아니다.
3. **큰 문맥과 추론 비용.** 전체 질문 입력은 약 4만 자이며 v10은 12,196토큰·1,157.897초, v11은 9,069토큰·931.260초를 사용했다. 지시문이 달라진 단일 사례이므로 이 차이를 속도 개선 성과로 계산하지 않는다. 관측된 일부 Builder·Critic·적용성도 기본 timeout 360초를 넘었다. 설정 확대는 실행 가능성을 개선했지만 속도·비용 병목을 해결하지 않았다. 현재 결과는 명시한 설정에서만 확인됐다.
4. **진단 사본과 처음부터 끝까지의 제품 실행 차이.** 이번 T2는 실제 과거 후보·수정·검수를 가져온 미승인 진단 사본이다. 좁은 질문 사본의 CQ 귀속을 원래 전체 질문으로 복원하는 과정에서 outer/nested 귀속 불일치도 발견해 정정했다. 이것을 모델이 원문 누락을 새로 복구한 실적으로 계산하지 않는다. 재사용의 유효성은 확인했으나 무시드 전체 실행의 품질 증거는 아직 없다.
5. **후속 산출물과 일반화 미확인.** 실제 계층 생성·양방향 검수·선택 의존성을 포함한 A3 미리보기(T3), 다른 공식 설명에서의 무시드 생성(T4)은 아직 실행하지 않았다. 준비된 코드·입력은 완료 증거가 아니다. 반복 노출된 개발 자료의 개선을 보지 않은 자료의 일반 품질로 확장할 수 없다.
6. **사람 효용 미측정.** 실제 참가자가 없어 같은 품질에서의 사람 작업시간·오류 감소는 측정하지 않았다. 코드 검사와 AI 전문가 검수는 이 측정을 대신하지 않는다.

## 다음 작업에서 이어갈 개선 순서

- **우선 해결:** 제공되지 않은 법적 연결을 추출 누락으로 바꾸는 경계를 바로잡는다. v11의 상위 포함 `unknown`과 하위 동일성 `extraction_missing`이 요구하는 전제를 나란히 대조하고, 제공 원문에서 실제 확인된 의미만 기존 후보와 비교해 복구 대상으로 삼아야 한다. `supported`를 보류로 바꾸는 것만으로는 해결되지 않으며, 권한의 존재와 실제 기준 내용도 분리해야 한다. 같은 문구 추가·같은 호출 반복 전에 이 실패 위치를 고정한다.
- 전체 질문의 의미 경계가 확인되면 T3에서 실제 생성 계층과 필요한 유형의 현재 검수, 양방향 이유·근거, A3에 실제 포함된 계층·전이 의존성 ID를 확인한다. 미리보기 성공 표시만으로 포함을 주장하지 않는다.
- 이후 T4에서 기존 공식 5년임대 설명 한 건만 사용해 무시드 실제 생성과 같은 CQ를 확인한다. 운영 기간의 기준 시점, 분양전환 기회의 대상·시점, 관리와 공급의 구분을 현재 후보 및 A3 포함 목록까지 연결한다. 자연 발생 오류가 없으면 교정 효과는 미측정으로 남긴다.
- 처리 비용은 의미 기준을 통과한 고정 사례에서 분석한다. 출력 장황함·필수 검수 중복·문맥 범위를 측정한 뒤 기존 단위·재사용 경로에서 줄인다. 먼저 원문을 잘라 버리거나 필수 의미 검수를 생략하지 않는다.
