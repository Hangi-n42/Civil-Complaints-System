# LH 운영 원장 공개 확보 가능성과 시연 범위

- 확인일: 2026-09-29
- 목적: 문서와 단지 자료를 늘리는 것으로 동호 변경의 실제 영향을 계산할 수 있는지 확인.
- 조사 방법: 기존 수집 명세·단지 CSV·결정문 재검토, 공공데이터포털 공식 명세 확인, LH 계약·예비입주자 조회 경로 비로그인 접근.
- **결론: 확인한 공개 경로에서는 동호·계약·배정·대기·수선을 동일 시점으로 연결한 운영 원장을 확보하지 못함. LH 시연은 문서·조건 변경 영향과 근거 검토로 구성.**
- 공개 원장이 어디에도 없다는 전수조사 결론은 아님. 기관 협력으로 제공받을 수 있는지도 현재 미확인.

## 2. 데이터 양보다 부족한 연결

- 단지 CSV 6,217행은 단지 수준의 폭을 제공하지만, **동호 변경의 영향 단위는 동호·계약·배정·대기자**.
- 현재 추출 범위는 양산 공고에 연결된 6개 단지. 전체 CSV 보유와 실제 연결된 지식 범위를 구분.
- 신규 실제 LH 관련 자료는 제주 2023 문의, 하남 2024 민원, 울산 2024 결정문. 기존 양산 2026 공고와 같은 업무 사건이나 모집 범위가 아님.
- 익명 주택과 민원인을 추측으로 실제 양산 단지·가구에 연결하지 않음.
- 공개 공고·공급 API를 추가해도 개별 주택의 현재 계약·대기 관계가 자동 복원되지는 않음.

### 동호 변경 결정문을 영향 계산으로 오인하지 않을 기준

- 결정문 4쪽에는 기존 주택에 예비입주자가 없어 다른 입주예정자의 피해가 없다는 판단, 계속 거주 시 수선이 불필요하다는 판단, 다른 주택을 새 예비입주자에게 공급할 수 있다는 판단이 이미 제시됨.
- 이를 추출·연결하여 같은 결론을 보여주는 것은 **기관의 판단 근거 재현**. 별도 원장을 조회해 시스템이 독립적으로 영향을 발견한 결과는 아님.
- 그래프에 대기자 노드가 없다는 이유로 대기자가 없다고 판정할 수 없음. 해당 시점 원장의 완결성 또는 명시적 사실 근거 필요.
- 수선비·대기기간·실제 수혜 또는 피해 가구 수는 이 자료로 계산하지 않음. 결정문에 기재된 임대조건 차이를 수선 절감액으로 바꾸지 않음.

## 3. 운영 영향 분석에 필요한 기관 협력 자료

- 다음 자료를 동일 공급군·기준시점으로 연결한 가명 원장 묶음이 필요. 실명·주민번호가 필요한 것은 아님.
- 공개 자료로 완결된 묶음을 확보하지 못했으므로, 운영 영향 분석을 추진할 경우 제공기관과의 협력 가능성 확인 필요. 협의·제공 승인 가능 여부는 미확인.

| 원장 | 최소 필드 | 가능해지는 검토 |
|---|---|---|
| 주택 상태 | 동호 ID, 단지 ID, 공급유형·면적, 점유·공가·공급 상태, 유효시점 | 두 주택의 변경 가능 상태 |
| 계약·배정 | 가명 신청인 ID, 계약 ID, 동호 ID, 배정·취소·계약 시점과 상태 | 중복 배정·계약 충돌 |
| 대기 | 공급군·주택형, 가명 대기자 ID, 순번, 자격·배정 상태, 기준시점 | 다른 대상자의 공급 기회 변화 |
| 수선·입주 | 동호 ID, 작업 필요·진행 상태, 확인된 비용·기간, 입주 가능일 | 수선비·입주 일정 변화 |
| 변경안·규칙·결과 | 기존/변경 배정, 유효일, 규정 버전, 실제 승인·배정·입주 결과 | 제약 검토와 예상·실제 결과 대조 |

- 비용을 비교하지 않는 업무 범위라면 비용 항목은 제외 가능. 대신 비용 절감 효과도 산출 대상에서 제외.
- 일부 개인의 순위만으로는 같은 공급군의 다른 이해관계자에 대한 누락 없는 영향 검토 불가.
- 합성 운영 원장을 만들 경우 구현 동작 확인용으로 구분. 실제 LH 영향을 실증한 데이터로 표시하지 않음.

## 4. 현재 자료에 맞는 LH 시연 범위

**핵심 질문: 공고나 조건이 바뀌었을 때 어떤 업무 지식과 답변을 다시 확인해야 하는가?**

1. 기존 양산 공고의 원본·정정본에서 실제 바뀐 항목과 원문 위치 확인.
2. 변경된 조건·일정·공급 정보를 해당 단지·주택형·절차·서류·안내와 연결.
3. 그 근거를 사용하는 질문·답변·검토 항목을 재검토 대상으로 제시.
4. 담당자가 변경의 적용 범위와 근거를 확인하고 답변 수정 여부 결정.

| 구분 | 시연 내용 |
|---|---|
| 관계 구축 | 공고 버전 → 변경 항목 → 적용 대상 → 조건·서류·기관 → 답변 근거 |
| 계산·집계 | 실제 변경 항목, 등록된 지식 중 영향 경로가 확인된 항목, 재검토 대상 답변 |
| 근거 검토 | 민원 요구와 적용 조건의 일치, 구버전 사용 여부, 빠진 요구 확인 |
| 범위 밖 | 실제 피해 가구 수, 대기순번 지연, 수선비 절감, 실시간 동호 배정 영향 |

- 아직 발생하지 않은 답변 수정이나 실제 이용자 피해를 만들어 넣지 않음. 기존 답변이 없으면 새로 작성한 평가 질문·답변임을 표시.
- 실제 민원은 해당 지역·사업·시점의 근거를 갖춘 경우에만 답변 검토 입력으로 사용. 동호 변경 결정문은 별도의 역사적 판단 재현 사례로 보존.
- 관계를 활용한 재검토 대상 탐지가 단순 문서 비교보다 유용한지는, 같은 변경에 대한 핵심 누락과 검토 시간을 비교하여 확인. 이번 자료 조사에서 효용을 입증한 것은 아님.

## 5. 완료 결과와 다음 작업

- 진행 이유: 공개 데이터 양과 개별 운영 관계의 완결성을 구분하여 구현 가능한 시연 범위 확정.
- 결과: 단지·공고·공가 집계의 제공 범위 및 개인 조회의 인증 요구 확인. 현재 공개 확보물로 운영 원장 기반 동호 변경 영향 측정은 불가. 문서·조건 변경 영향과 근거 검토는 진행 가능.
- 다음 작업: 기존 양산 공고군의 실제 변경 항목을 고정하고 연결할 조건·안내·질문 목록 작성. 동호·배정 시연 확대는 기관 협력으로 필요한 원장 확보 시 재검토.
- 사용자 결정 사항: 현재 범위에 추가 결정 불필요. 향후 실제 LH 운영 영향까지 확대하려면 기관 협력 추진 여부 결정 필요.
- 조사 보고서만 추가. PRD·구현 코드·기관 계정·신청 상태 변경 없음.
