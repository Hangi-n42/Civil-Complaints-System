# J1 역할별 집중 검수 입력 준비

- 관련 이슈: #566, 상위 #534/#539. I3에서 정상 조건을 누락으로 판단하고 원문 밖 정의를 지지한 오류에 대응한다.
- 기존 review_context/make_prompt/call을 재사용하여 관계와 관측·계층을 주후보 최대 2개로 분리한다. 원후보·지문·서버 ID·원문 및 연결 후보를 유지하고 제외 문맥을 기록한다.
- 역할별로 필요한 지시와 공통 근거 규칙만 제공하고, 기존 reason 안에서 원문과 후보 문구를 직접 대조한다. 출력 계약이나 의미 판정 규칙을 새로 만들지 않았다.
- 양쪽 종류를 비교할 수 없는 입력은 missing_meanings를 비우고 미실시 범위를 표시한다. 좁은 후보 검수가 전체 의미 완성을 뜻하지 않는다.
- 기존 비교 묶음의 끝점 오류 면제는 실제 주검수 묶음에 정상 연결이 있을 때만 적용하도록 수정했다. 주검수 소유자가 없는 미연결 후보를 정상으로 취급하던 회귀를 관련 검사에서 발견했다.
- 기본 직렬 실행기는 기존 검수 경로를 유지한다. 준비된 분할 경로의 기본 연결은 J2 실제 진단 통과 후 J3에서만 수행한다.

- 의미·실행 전문가 검토 및 축소 프롬프트 최종 확인 완료. 실제 모델 호출 0회; 의미 품질 향상은 아직 미측정이다.
