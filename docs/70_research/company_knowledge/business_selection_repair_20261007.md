관련 회귀 검사 6개 파일 173개가 225.24초에 통과했다. 마지막 검토에서 부분 재판정이 오류 메타데이터만 지우고 자기 전제를 유지하는 경우도 계속 차단하도록 `answer_scope_issues`만 보완했다. 이후 해당 경계 파일 31개가 7.48초에 통과했다. 두 검사 수에는 중복이 있으며 합산하지 않는다. 네 동결 E 요청은 이 마지막 보완 전후 정확히 같고, 나머지 실제 실행 모듈도 불변이다. `final_runtime_code_audit.json`은 보완 전 일치 확인, `final_scope_guard_delta.json`은 마지막 함수 차이와 무모델 검증 기록이다.

검사에는 이전 판정 제거, 실제 주소 복원, 빈 목록의 추가 의미 경로, 정상/잘못된 선택의 혼합 보존과 완료 차단, 자기 전제, 조건 원문의 서버 표시, 공개 criterion 전달과 내부 판정 제거가 포함된다. 검사 통과를 모델 의미 품질이나 전체 요구 완료로 계산하지 않는다.

## 남은 작업과 사용자 결정

1. #616: 기존 복합 의미 선택만으로는 부가 업무가 필수 범위로 이동한다. 선택한 완결 명제의 조건·예외·기간까지 실제 원문으로 정정하는 경계와, 국소 미발견의 요구 전체 귀속이 남았다. 같은 prompt의 추가 반복이나 의미 수 감소로 완료 처리하지 않는다.
2. #617: c116 실제 교정·저장·정상 보존·동일 R05 재검수·그래프 반영은 기존 증거로 확인됐다. 그러나 그 상태의 정확한 전체 업무 답변은 아직 실패한다. 과거 교정 성공과 남은 활용 실패를 구분한다.
3. #620: 공개 기준을 제공하는 것, 정확히 발췌하는 것만으로 요청 항목을 충족하지 못했다. 문서 조건, 직접 제외, 허용 미확인, 요청 항목 누락을 답변에서 실제 구별하는 책임이 남았다. 새 judge나 모델 역할 변경의 근거로 사용하지 않는다.

이번 범위의 구현·제한 검증은 종료하고, 미완료 품질 경로는 열린 상태로 보고한다. 이슈 종료는 수행하지 않았다. 현재 사용자 결정이 필요한 사항 없음.

기존 이슈 본문을 다시 읽었다. 세 이슈의 공통 완료 원칙은 저장 수정·정상 보존에서 끝나지 않고 같은 요구와 그래프·검색을 거쳐 올바른 답변까지 요구한다. [#616](https://github.com/Hangi-n42/Civil-Complaints-System/issues/616)은 요구 밖 의미의 필수 전파가 남아 있고, [#617](https://github.com/Hangi-n42/Civil-Complaints-System/issues/617)은 실제 교정 이후의 답변 정확성이 미달하며, [#620](https://github.com/Hangi-n42/Civil-Complaints-System/issues/620)은 부산 필수 종단 기준이 미충족이다. 셋 모두 전체 완료로 판정하지 않으며 확인 당시 open 상태를 유지한다. 본문·상태는 `final_issue_criteria.json`에 보존했다.
