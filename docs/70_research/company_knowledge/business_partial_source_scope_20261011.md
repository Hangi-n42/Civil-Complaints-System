## 채택한 코드 경계

- 부분 재판정은 기존 최초 조사의 현행 의미 타입과 `inspection_status`/typed `findings` 계약을 재사용한다. 공개 질문 적용성 문맥, 선택 key, 필수 조건·참조, 형제 의미 보존 검사는 유지한다. 전체 요구 `completeness`/자유 `gaps`는 이 국소 호출의 출력 책임에서 제외한다. 실제 의미 귀속 공백은 기존 `meaning_gaps`로 연결하며 과거 공백·finding을 지우지 않는다.
- 새로운 `reassessment_history`에 서버가 실제 제공한 구간, 본문 target, 선택 의미, 원문 버전, 모델이 보고한 examined 구간과 조사 오류를 구분해 남긴다. `inspection_summaries`로 종합에 전달하되 선택 의미 검수를 전체 원문 조사 완료로 세지 않는다. 과거 기록에 없는 제공 범위나 조사 상태는 추정하지 않는다.
- 미귀속 관측은 조사 범위를 기록하고 정상 의미의 오류로 자동 귀속하지 않는다. unresolved는 전체 요구 미확정으로 남는다. 불완전 조사·범위 불일치는 기존 `pending_inspections`→`needs_source_read`에 연결한다. 제공 범위 밖 examined ID는 원 응답·receipt에 보존하고 조사 목록에 넣지 않는다.
- legacy source에 `source_selection`이 없으면 추가 읽기는 `legacy_source_selection_missing`과 `unknown`으로 중단한다. 전체 조사 receipt를 만들어 내거나 KeyError 뒤 새 전체 조사를 시작하지 않는다. 이 legacy 상태의 실제 전체 조사·종합은 미실행이다.
