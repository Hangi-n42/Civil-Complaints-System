# 한국어 추론 판단기 교체 진단 — 2026-10-09

연구 #631의 이번 HyperCLOVA 구성은 **제품 기본 판단기 대체 후보로 기각**했다. 조율 세션이 원문과 실제 최종 출력을 직접 대조해 결정했다. EXAONE 4.0은 현재 제품 개발 목적의 이용 허용 근거가 확립되지 않아 실행하지 않았다. 자동 교정·저장·그래프/검색·같은 질문 QA는 새로운 검출 개선 근거가 없어 연결하지 않았다. 연구 비교 완료와 #616/#617/#620의 전체 제품 목표 완료는 다르다.

## 진행 이유와 고정 범위

기준은 `feature/business-knowledge-repair-retrieval`의 `4d5f8c0d32eafa51ba2717f6b11cd106f9845ab2`다. 과거 입력 축소·조건 구조화 등의 실패 변형을 반복하는 대신 공개 한국어 추론 모델로 기존 판단 호출을 대체할 근거가 있는지 작은 진단을 수행했다. 새 검수 계층을 추가하지 않았다.

원문·후보·기준·노출 이력·프롬프트·코드·설정을 생성 전에 동결하고 조율 세션에 전달했다. `freeze.json` SHA-256은 `bde7233b462da6f270eac79b206c76ee4a90006f14747432ab831c0adc00cfc6`이다. c13/c46/c47/c11 → H01–H08 → A01/A02 → K01/K02 순서로 실행했다. c47 실패가 다른 진단을 중단시키지 않았다.

- 차량 4건은 노출된 개발 사례다. c47과 저장된 m7은 같은 원문 오류이며 독립 문서 두 건으로 세지 않는다.
- 박물관 H/A 10건도 이미 노출된 확인 사례다. H07의 사전 고지 대체/사후 의무 추가 해석 모호성은 그대로 보존하고 합의 분모에서 제외했다.
- 부족한 ‘가능 → 의무’ 대조만 K01/K02로 추가했다. `gpt-6-astra`, high, 별도 문맥의 작성·맹검 검토가 각각 K01 지지/K02 미지지로 판단했다. 같은 모델의 두 문맥이며 인간 검수나 독립 모델 합의가 아니다. 원문은 이미 노출된 동일 박물관 안내다.
- 총 원문은 **2개**다. 16문항을 독립 문서 16개, 새 K 2건을 미사용 문서 일반화 검증으로 해석할 수 없다.
- 모델에는 원문 블록·기존 부모 관계·후보만 제공했다. 평가 라벨·오류 해설·원하는 수정문은 별도 파일로 유지했다.

## 모델과 실제 실행

[원본 HyperCLOVA X SEED Think 14B](https://huggingface.co/naver-hyperclovax/HyperCLOVAX-SEED-Think-14B/tree/9b74e35d4c7e4ffec489f4171273caca8948a2b9)의 revision은 `9b74e35d4c7e4ffec489f4171273caca8948a2b9`, [제공자 GGUF](https://huggingface.co/naver-ellm/HyperCLOVAX-SEED-Think-14B-GGUF/tree/89b9a40202ccd54b21d0120d620b37858e32d5e7)는 `89b9a40202ccd54b21d0120d620b37858e32d5e7`이다. Q4_K_M 파일은 8,916,242,240 bytes, SHA-256 `34189c1048e57b9b0025058114185ce4dc37d045596666b67e377ef1f08398c0`과 일치했다. 마지막 다운로드 구간의 시간 초과 후 HTTP 206/Content-Range를 검증해 누락 바이트만 이어 받았다. 최초 실패 로그도 보존했다.

[제공자 llama.cpp 포크](https://github.com/NAVER-Cloud-HyperCLOVA-X/llama.cpp/tree/e586ccd57b33b275ae5bfbb5278ba6fd63318c20) `e586ccd57b33b275ae5bfbb5278ba6fd63318c20`을 CMake 3.31.6, Release, Metal, `LLAMA_CURL=OFF`로 빌드했다. Apple M4 Max/36 GiB에서 localhost 전용 서버, 단일 슬롯, context 16,384, 출력 상한 4,096, 추론 길이 안내 1,024, temperature 0.5, top_p 0.6, repeat penalty 1.05, seed 42를 사용했다. 추론 길이 안내는 강제 상한이 아니다. top_k/min_p는 비활성화하고 전체 문맥 반복 페널티를 설정했다. 실제 서버 적용값도 원시 응답에 보존했다.

공식 `tool_list → system → user → assistant/think`를 사용했다. **첫 실행에서 포크의 일반 종료 처리 결함이 확인됐다.** `<|im_end|>`가 EOG로 등록되어 추론 메시지를 끝내는 순간 최종 assistant 답변 전에 멈췄다. 공식 모델 문서는 그 뒤 최종 답변을 생성하고 `<|endofturn|>` 또는 `<|stop|>`에서 멈추도록 한다.

이 때문에 모델 종류가 `hcx-seed-think`일 때만 `<|im_end|>`를 EOG에서 제거하고 `<|endofturn|>`/`<|stop|>`을 등록하는 제한된 런타임 패치를 적용했다. 공식 포크 원본과 이 로컬 패치를 구분한다. 커밋용 패치의 빈 문맥 줄 공백만 정리했으며, 실행본 패치도 별도 보존하고 두 패치가 동일한 실행 소스에 대응함을 검증했다. 패치·소스·바이너리 해시를 새 실행 전에 기록했으며 원래 freeze, 문항, 기준, 프롬프트, seed, 샘플링은 바꾸지 않았다. 이는 의미 실패를 개선하려는 재시도가 아니라 최종 답변을 받기 위한 실행 계약 수정이다.

최초 결함 실행 5요청 중 4개 원시 응답을 저장했다. H01은 서버 완료 로그가 있으나 클라이언트 중단으로 응답 본문을 저장하지 못했다. 이를 복원하거나 의미 결과로 사용하지 않았다. 수정 후 16건은 모두 최종 assistant 경계를 거쳐 `<|endofturn|>`로 종료됐고 문맥/출력 잘림은 0건이었다.

## 비용과 EXAONE 미실행

유효 런타임 16건의 클라이언트 호출 시간 합은 **218.17초**, 입력 27,545토큰·생성 4,809토큰이다. 최대 입력+출력은 2,445토큰으로 16,384 문맥 내였다. 최초 EOG 결함 실행 5건은 별도로 입력 7,108·생성 845토큰, 서버 prompt+generation 합 43.36초가 들었다. 총 생성 요청은 21건이며 이를 16건 비용에 숨기지 않는다. 다운로드·빌드·모델 로드 비용은 이 추론 시간에 포함하지 않았다. 종료 시 관측 RSS는 약 15.19 GiB이며 피크 측정은 아니다. 진단 서버는 종료했다.

[HyperCLOVA 공개 라이선스](https://huggingface.co/naver-hyperclovax/HyperCLOVAX-SEED-Think-14B/blob/9b74e35d4c7e4ffec489f4171273caca8948a2b9/LICENSE) §2.2의 조건부 이용 허용과 §4의 추가 상업 조건, 재배포/AUP 조건을 보존했다. 이번 로컬 진단이 별도 서비스 배포 권한을 확정한 것은 아니다.

[EXAONE 4.0 원본 라이선스 1.2-NC](https://huggingface.co/LGAI-EXAONE/EXAONE-4.0-32B/blob/a1d54d1c148c30881ed27e035b650da489b51b92/LICENSE)의 §2.1은 연구·교육 목적, §2.2는 그 밖의 이용 제한, §3.1은 직접·간접 수익을 내는 제품/서비스 개발을 포함한 상업 이용 제한을 명시한다. 현재 작업은 제품 판단 개선 목적이고 허용되는 비상업 목적 또는 별도 권리자의 허락이 확인되지 않았다. 따라서 명칭만 연구로 바꾸지 않고 **가중치 다운로드·실행 모두 하지 않았다**. 메타데이터·README·라이선스만 확인했다. EXAONE의 품질/속도 결과는 없으며, 기존 3.5 실패와도 구분한다.

## 보존·검증·다음 작업

[전체 JSON 증거](business_korean_judge_20261009.json)에 동결 자료, 원시 요청/응답, 실패 실행, 토큰·시간, 원문 대조, 별도 평가자료, 라이선스, 관련 과거 호출을 포함했다. 이전 결과의 무관한 전체 DB/그래프 사본은 다시 중복하지 않고 해당 원본 파일 해시와 관련 호출을 보존했다. 가중치·실행 바이너리는 Git에 넣지 않았다.

재현 스크립트는 `scripts/compare_business_korean_judge.py`, 제한된 패치는 `scripts/patches/hyperclovax_think_eog.patch`다. JSON의 `artifacts`는 평가 루트 상대 경로, `external_inputs`는 저장소 상대 경로다. 해시 검증용 원문 바이트는 저장소 상대 경로를 키로 갖는 `frozen_text_files`의 UTF-8 문자열을 그대로 복원한다. 별도 연구 checkout에서 자료를 복원하고 기존 실행 증거를 보존한 다음, 고정 GGUF 검증 → 고정 포크+패치 빌드 → `runtime_launch.json` 명령 → 스크립트 `run` 순서로 실행할 수 있다. 이번 기각 구성을 동일 원인으로 반복할 권고는 아니다. GPU의 비트 단위 결과 재현성을 주장하지 않는다.

관련 파서/추론 경계/후보 ID/필드/정확 인용 테스트 **8건 통과**. 실제 런타임 전환과 16건 완주도 확인했지만 이는 제품 의미 품질 성공이 아니다. 제품 기본 경로와 기존 교정 결과는 변경하지 않았다. #631 종료는 조율 세션의 최종 확인에 맡기고, #616/#617/#620은 이 연구만으로 닫지 않는다. 다음 제품 작업은 기존 이슈의 정상 의미 보존·실제 교정·같은 요구/활용 결과를 각각 검증해야 한다. 현재 사용자 결정이 필요한 사항 없음.
