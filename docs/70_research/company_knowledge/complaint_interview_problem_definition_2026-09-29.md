# 민원 문제 정의 — 인터뷰 활용 기록

- 반영일: 2026-09-29.
- 출처: 팀원 조사 결과를 사용자가 대화에서 제공한 부산 콜센터 관리자 인터뷰 요약.
- 인터뷰 일시·원본 녹취·기관 통계 원본: 미제공. 아래는 인터뷰 진술이며 독립 확인된 기관 통계와 구분.

## 제품 요구에 반영한 진술

| 진술 | 설계 반영 |
|---|---|
| 전화·문자·채팅은 Genesys로 통합 관리 | 기존 콜센터 채널 통합을 제품의 핵심 과제로 설정하지 않음 |
| 국민신문고 등 문서 민원은 별도 운영 | 사건 통합과 공통 지식 공유를 구분 |
| 사람이 대·중·소분류 수행 | 반복 업무 후보로 기록하되 자동화의 순편익 측정 |
| 주관부서·협조부서 협업 후 주관부서 단일 회신 | 기존 배분·회신 절차를 보존하고 요구별 근거·답변 검토 지원 |
| AI·음성 처리·시스템 연동 비용과 예산 우선순위 부담 | STT/TTS 신설보다 기존 문서 민원 흐름의 제한된 시범 적용 우선 |
| 용어 불일치 불만을 접하지 못했다는 관리자 답변 | 용어 혼동을 현장의 최우선 고충으로 단정하지 않음 |

## 수치·전언의 사용 기준

- 월 총 17,758건, 전화 17,107·문자 604·채팅 47건: 사용자 제공 요약에 포함된 수치. 조사 월은 특정되지 않음.
- 별도 제시된 채널 비율은 월별 건수 기준과 일치하지 않아 PRD의 정량 근거에서 제외.
- 일일 약 850건·차량등록 약 50%·타 지자체 약 95% 유사 운영: 현장 발언으로 보존하되 시장 전체 통계로 사용하지 않음.
- 서울시 AI 예산·삭감, 부산 모바일 앱 폐기 및 원인: 전언·해석 포함. 공식 사업·예산 자료 확인 전 도입 실패의 실증 근거로 사용하지 않음.
- 공공 데이터가 적어 민간 LLM보다 품질이 낮다는 설명: 인터뷰이의 원인 해석. 기관 업무자료 규모와 기반 모델 사전학습 규모를 동일 기준으로 비교하지 않음.

## 후속 현장 확인

- 대상: 국민신문고 담당자와 주관부서 실무자.
- 사례: 비식별 문서 민원 한 건의 접수 → 요구 확인 → 배분 → 근거 확인 → 협조 → 회신.
- 확인: 반복 탐색·대기·수정 구간, 기존 도구, 필요한 지식과 접근 권한, 건별 사람 시간.
- 제품 가설: 공통 업무 지식과 요구별 근거 대응이 답변 준비·통합 검토 부담을 줄이는지 확인.
- 범위 구분: 부산 인터뷰는 민원 활용 요구의 근거. LH 공개자료는 회사 지식 구축 파일럿 자료이며 두 기관의 업무 체계를 동일시하지 않음.
