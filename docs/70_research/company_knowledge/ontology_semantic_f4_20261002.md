# F4 포함 구간의 본문 중복 제거

- 관련: #549. 같은 블록의 큰 연속 구간 안에 완전히 포함되고 본문이 일치하는 작은 뷰는 text_from으로 본문만 공유한다. 작은 source_ref/span과 분석/문맥 역할은 유지하며 부모 구간 밖 참조를 거절한다. 부분 겹침·분리 구간·다른 블록은 합치지 않는다.
- 저장 원문이나 성공 unit은 바꾸지 않고 prompt v29의 직렬화에만 적용한다. 상한/예약 증액, 요약, 조건 삭제는 없다. 원문 위치 합집합·인용 해석을 유지한다. 빈 내부 메타데이터도 모델 입력에서만 생략한다.
- 저장 E4 사례를 당시 dd5ef54 코드로 재조립하여 12,521자를 재현했다. 같은 선택 문맥을 새 formatter로 구성하면 압축 전12,530 → 압축 후10,850자다. 실제 순감소1,680자는 작은 구간 참조 메타데이터 비용을 포함한다. 단순 본문 차감 예상10,687자를 측정치로 쓰지 않는다.
- 본문 제공8뷰의 source_ref/span/본문/역할, 모든 인용 재해석이 동일하다. D5 원 result/DB 해시 불변. 무모델 재조립과 보고는 로컬 `data/knowledge/semantic_f4_20261002/`에 보존했다.
- 12,000자 입력 상한 여유1,150자는 확보했지만 Concept 예약2,000자를 포함하면 **850자 부족**하다. 예약을 포함한 전체 입력 적합성을 달성한 결과가 아니며 기존 미처리 사유를 유지한다.
- 구간·계약·복구49개 통과. 이후 입력 영향 검사127개 통과/1개 실패에서 빈 메타데이터로 7자 초과한 경계를 수정했다. 해당 실패와 구간·계약을 재확인한36개 모두 통과(2.18초), 기존 경고13개. 겹치는 검사 수는 합산하지 않는다.
- 실제 모델 호출0. 다음 F5에서 새 동결로 C2 한 번을 확인하고 독립 의미·모델 산출만의 유효 preview를 통과할 때만 current로 진행한다. 현재 사용자 결정이 필요한 사항 없음.
