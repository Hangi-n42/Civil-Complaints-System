## A의 입력·출력·결합 경계

원래 8건과 SL-01/02/03의 원문·후보·ID·부모를 변경하지 않고 지지 조사와 배제 조사에 동일하게 제공한다. 두 호출은 상대 응답이나 이전 최종 라벨을 받지 않는다. 생성 정정문·사람의 올바른 연결·정답을 입력하지 않는다. 정확 prompt 22개는 `prompts.json`, 실행 요청 token IDs는 `requests.json`에 있다.

지지의 established는 필요한 의미 연결을 포함한 전체 후보 지지, not_established는 실제 추가·강화·범위·전체성 주장의 미입증 관계를 특정한 판단이다. 빈 검색 결과와 다르며 구체적인 unestablished_requirement·관련 원문·실제 문제 구절을 요구한다. 배제의 established는 같은 대상·조건·시점에서 명시된 반대, not_established는 조사한 제공 텍스트에서 그러한 배제가 성립하지 않았다는 판단이다. 현실의 참·면제·금지를 의미하지 않는다.

두 조사 원본과 자료 상태는 별도로 보존한다. required_reference_missing/missing 자체로 U를 생성하지 않는다. 제공 텍스트 조사는 완결됐으나 필수 참조 전문이 없는 경우 명시적인 두 조사 판단으로 얻은 U와 참조 부재/운영 hold가 공존할 수 있다. 직접 기준선은 사례별 #638 최신 reason-first 8+3 응답으로 고정한다. 라벨 정답은 8/11이지만 A02의 자료 상태와 SL-02 이유 오류를 포함한 축별 기준을 유지한다. 과거 중 유리한 응답을 선택하지 않는다. 신규는 11×2=22회다. 정상 K01/c13/c46/SL-01/SL-03, 명시 반대 C05, 오류 K02/C04/c47/SL-02, A02 자료 상태를 각각 보고한다. 최소 진행 근거는 기존 의미 오답의 정확한 개선과 정상·기존 올바른 의미 보존이며, 부분 효과를 전체 달성으로 올리지 않는다. 모두 미확정·형식만 개선·정상 손상이면 현재 구성을 기각한다. c47은 유일 관문이 아니지만 자체 교정에는 자체 정확 검출이 필요하다.

## B의 실제 최소 구현과 기준

서버 `source_packet`은 원문 각 블록을 개행 포함 행 구간으로 나누고 다시 이어 붙인 문자열이 원본과 같은지 검사한다. 선택 입력에는 각 행 ID와 실제 텍스트를 한 번만 제시한다. 기존 블록 metadata·부모는 유지하며 제목·목록·문장·괄호의 의미를 서버가 해석하지 않는다. 서버 내부의 start/end·블록 SHA는 모델이 선택한 인용을 복원할 때 사용한다.

모델 출력은 omitted_argument/condition/exception/period/reference 종류의 `from → target` 원문 구간 선택, selected/ambiguous, 짧은 이유와 미해결 목록이다. 참조 전문이 없으면 그 내용을 만들지 않는다. 최대 6연결을 넘는 필요한 연결은 구체적인 unresolved로 남겨야 한다. 각 인용은 선택 행 안에서 정확히 한 번 나타나야 하므로 다른 행의 반복 구절도 구별한다. 새 전체 의미·규칙·조건 문장을 생성하는 ExtractionScope나 #627 자유 논리 구조화를 재사용하지 않는다.

서버는 선택 위치의 실제 존재·원문 버전만 검사하고 반환 주소에 `precision=exact_unverified_meaning`, 연결 전체에 `semantic_status=unverified`를 붙인다. 의미가 잘못된 유효 주소도 사람이 걸러내거나 고치지 않고 B2에 전달한다. 주소 계약 실패는 원본과 분모에 남기고 B2를 실행하지 않는다. 비어 있거나 미해결인 유효 출력은 그대로 전달하며 성공으로 세지 않는다.

B2는 #638의 동일 원문/후보 표시와 reason-first 판정 지시를 유지하고 `automatic_scope_links` 및 그 미검증 사용 경계 한 문장만 추가한다. B1 선택용 주소화 원문으로 B2 원문을 대체하지 않는다. 전체 원문과 다른 구간의 의무·예외·참조를 직접 대조하도록 하며, 유효한 주소를 지지나 의무 부재의 증명으로 쓰지 않는다. 연결과 사용 지시가 함께 달라지므로 순수 주소값만의 인과 효과를 주장하지 않는다.

대상은 K02/C04의 연결 공백과 K01 정상 가능, SL-03 정상 명시 의무, C05 명시 반대의 5건이다. B1 선택과 B2 판단 각 5회, 최대 10회이며 고정 기준선은 #638 같은 판단 구성의 저장 응답이다. B1의 주소 정합·실제 의미 적용 연결·미해결과 B2의 의미 판단을 분리한다. K02의 정확 U 개선 및 기존 정답 4건 보존, 필요한 연결의 의미 정확성을 검토한다. C04의 U 유지와 주소 처리만의 성과를 새로운 오류 검출로 계산하지 않는다.
