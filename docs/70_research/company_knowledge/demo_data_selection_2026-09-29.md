# 민원 및 버스 정류장 시연 자료 선정

- 조사일: 2026-09-29
- 기준: [회사 지식 PRD 4.1~4.4](../../00_overview/company_knowledge_prd.md), [민원 시스템 PRD](../../00_overview/complaint_system_prd.md)
- 목적: 같은 지식 계층으로 **요구별 근거를 연결하는 답변 지원**과 **변경에 연결된 대상의 영향을 비교하는 판단 지원**을 각각 시연.
- 상태: 자료 선정과 원문 확보 완료. 시스템 반입, 시연 입력 확정, 거리 계산 및 품질 평가는 후속 작업.
- 충분성 재검토: [LH 및 버스 데이터 판정](demo_dataset_sufficiency_review_2026-09-29.md). 기본 연결 착수 가능과 운영 영향 측정 자료의 완비를 구분. LH 운영 원장과 버스 변경안·보행 연결은 미완성.
- 후속 조사: [실제 LH 관련 시민 문의·LH 결정문·버스 노선 변경 민원 확보](real_complaints_and_impact_demo_2026-09-29.md). 아래 최초 선정안과 별도로 실제 원문 사용 대안을 정리.

## 1. 선정 결론

| 구분 | 우선 선정 | 선정 이유 | 보여줄 핵심 |
|---|---|---|---|
| A. 민원 | LH 국민임대 제출서류·발급기관·청약통장 재사용 복합 문의 | 공식 안내·Q&A와 기존 공고군을 연결 가능. 기존 지식 자산 재사용 | 질문의 각 요구에 맞는 조건과 근거 선택, 통합 답변 검토 |
| B. 버스 | 서울 도봉보건소 1127번 승차 정류장 변경, ARS 10118 → 10011 | 공식 변경 사유와 승인 기록, 변경 전후 노선 순서·정류장 좌표, 보행망 확보 | 같은 조치가 출발지별 접근 경로에 미치는 차이를 비교 |

- **두 사례 모두 자료 기반으로 개발 착수 가능.** 시연 성공이나 정확도까지 확인한 결과는 아님.
- A는 공식자료 기반의 **재구성 문의**로 사용. 실제 접수된 시민 민원 원문으로 표시하지 않음.
- B는 실제 변경을 소재로 한 비교. 공용 정류장 하나의 좌표를 옮기는 모델보다 **1127번의 정차 관계를 기존 정류장 두 곳 사이에서 바꾸는 모델**이 자료와 일치.
- 현재 PRD의 정류장 이전 범위를 구체화할 때 위 정차 관계 변경을 포함하는 것이 적절. 이번 조사에서는 PRD와 구현 코드를 수정하지 않음.

## 2. 넓게 조사한 후보와 선택 기준

- 우선 기준: 공식 원문 확보, 서로 다른 자료의 연결 필요성, 변경 전후 식별 가능성, 결과를 사람이 대조할 수 있는 정도.
- 실행 기준: 현재 지식 계층 재사용, 공개 한국어 자료, 작은 지역·한 건으로 완결 가능한 범위.
- 검색 노출이나 자료량만으로 선정하지 않고 실제 파일 내용과 식별자를 확인.

### 3.2 확인된 연결과 재구성 입력

- 제출서류 안내: `중소기업근로자 → 국민임대주택 우선공급확인서 → 각 지방중소벤처기업청` 연결 확인.
- 적용 범위: 해당 우선공급 대상의 확인서. 모든 신청자의 일반 제출서류로 확대하지 않음.
- Q&A: 분양전환되지 않는 공공임대 당첨 후 동일 통장을 다른 주택 청약에 사용할 수 있는 경우를 설명. 반대 방향의 당첨 이력까지 같은 규칙으로 처리하지 않음.
- 청약통장 사용 가능 여부와 특정 공고의 신청 자격 충족 여부를 분리.

**시연 입력 제안, 실제 접수 원문 아님**

> 국민임대 신청을 준비하고 있습니다. 일반 제출서류와 중소기업근로자 우선공급 대상일 때 필요한 확인서·발급처를 구분해 주세요. 국민임대에 당첨되면 사용한 청약통장으로 이후 공공분양에도 청약할 수 있는지 알려주세요. 선택한 양산 공고에서도 해당 우선공급을 신청할 수 있는지 확인해 주세요.

- 마지막 요구의 정답을 미리 “가능”으로 두지 않음. 해당 공고에서 우선공급 적용 여부가 입증되는지 먼저 대조.
- 시연 장면: 요구 분리 → 일반·조건부 규칙 구분 → 근거 위치 연결 → 공고에 적용 가능한 부분과 추가 확인 부분 구분 → 통합 답변 검토.
- 지식 그래프의 역할: `요구 → 모집/주택유형 → 적용 조건 → 서류 → 발급기관`, `규칙 → 근거 → 문서 버전`을 연결.
- 서류 발급기관을 민원 처리부서로 바꾸지 않음. 근거 없는 개인 자격 판정이나 이행 약속 제외.
- 변경 관리 확장: 근거 문서가 바뀌면 그 근거를 사용한 조건·답변 요구를 다시 확인할 대상으로 표시. 변경 사실과 영향 관계를 구분해 제시.

### 3.3 선택의 근거와 대안

- [국민권익위 공공주택 민원 분석](https://www.acrc.go.kr/board.es?act=view&bid=4A&list_no=8912&mid=a10402010000&nPage=1&tag=)은 주택 유형·기준·공급기관의 분산과 명칭 혼란을 설명. 2019년 자료이므로 현재 민원량 통계로 인용하지 않음.
- LH 선택 이유는 자료 친숙성뿐 아니라 **같은 문의 안에서 여러 출처의 규칙과 적용 범위를 연결할 수 있기 때문**.
- 부산 현장성과의 직접 연결이 더 중요해질 때는 [자동차 이전등록 안내](https://www.busan.go.kr/car/crtransfercar)와 [부서 안내](https://www.busan.go.kr/car/deptinfo)를 사용하는 대안이 적절. 명의이전 사유·본인/대리인·필요서류·업무 담당을 연결 가능.
- 두 도메인을 동시에 구현하는 범위로 확대하지 않음.

### 4.3 시연할 장면과 남은 확인

1. 1127번의 변경 전후 승차 지점을 같은 지도와 관계 경로에 표시.
2. 보건소 및 주변 실제 출입구 3~4개를 대표 출발지로 고정. 아직 출입구 목록·좌표를 확정하지 않았으므로 임의 명칭이나 결과를 입력하지 않음.
3. 같은 노선·방향·보행망에서 두 승차 지점까지 접근 경로와 거리 계산. 다른 이용 가능한 정류장을 포함하면 양쪽 조건에 동일하게 적용.
4. 출발지별 개선·악화·변화 없음·계산 불가와 경로 표시. 모든 결과가 한쪽으로 나오더라도 반대 결과를 만들기 위해 출발지를 사후 교체하지 않음.
5. 공식 변경 사유, 접근성 변화, 추가 확인할 쟁점을 나란히 보여주고 담당자의 변경안 검토 기록.

- **필수 확인 1: 출입구·승차 지점과 보행망의 접속 위치.** 도로 건너편의 가까운 노드를 자동으로 붙이면 횡단 경로가 누락될 수 있음. 선택한 지점만 지도·원문으로 대조.
- **필수 확인 2: 자료 시점.** 보행망은 카탈로그상 2020년 기준. 2025년 노선 변경 당시의 현장을 완전히 복원했다고 표현하지 않음. 최초 시연은 동일하게 고정한 보행망에서 두 승차 위치를 비교하는 조건부 분석으로 표시.
- 아직 보행거리·개선 대상 수·사고 감소·민원 감소를 계산하거나 검증하지 않음.
- 수요·개별 이동능력·신호대기 자료가 없으므로 실제 이용자 수와 이동시간을 거리에서 추정하지 않음. 고령자·장애인 영향은 확인할 쟁점과 실제 확보한 경로 특성을 구분.

### 4.4 왜 교수님 피드백에 적합한가

- 해결하려는 문제: 버스의 위험한 차로 변경을 줄이기 위한 승차 위치 변경.
- 연결된 영향: 노선의 승차 정류장이 바뀌면서 주변 출입구의 접근·횡단 경로도 달라짐.
- 시연의 차별점: 변경 제안의 이유만 요약하는 데서 그치지 않고, **어느 대상의 어떤 관계가 바뀌어 어떤 차이가 생기는지** 근거와 계산으로 설명.
- [국민권익위 민원 빅데이터 동향 제808호](https://www.acrc.go.kr/boardDownload.es?bid=1009&list_no=87686&seq=1) 3쪽은 익명 초등학교 앞 정류장 이전 관련 민원 **239건**과 안전·교통 개선 찬성, 추가 보행·오르막 접근 반대 논리를 제시.
- 239건은 해당 익명 사례의 민원 건수. 239명이나 이전 시행 후 새로 발생한 민원 수가 아님. 반대 의견의 200m도 민원인이 제시한 내용이며 측정값이 아님.
- **익명 사례를 도봉 사례의 주민 의견이나 발생 민원으로 연결하지 않음.** 도봉의 실제 찬반 민원 원문은 이번에 확보하지 못했으며, 유사 사례로부터 확인할 불편 유형만 참고.
