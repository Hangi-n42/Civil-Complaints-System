# F3 실행 내부 미승인 후보 비교

- 관련: #548. 기존 lookup/context를 사용해 같은 원문 구간 또는 원문에 명칭이 나오는 선행 미승인 관측을 최대5개 비교한다. 선택 결과를 묶음 최초 호출 전에 고정해 후속 산출이 성공 unit의 재개 입력을 바꾸지 않는다. 동일 명칭은 비교 단서이며 병합 근거가 아니다.
- Concept alignment에 승인 정본/실행 내부 대상 구분, 대상 내용·근거 지문과 원관측을 보존한다. Builder에는 실제 제공된 후보 사이의 유효 대응만 전달한다. exact_key는 느슨하게 바꾸지 않았다.
- A3는 실행 내부 same도 정본 update로 변환하지 않는다. 별도 add의 재사용 제안으로 보류하고 원관측·대상 스냅샷·대응 사유를 기존 검수 원장에 남긴다. 같은 이름이라도 조건이 다른 distinct는 분리한다. 자동 의미 병합은 없다.
- 대상 내용 수정, 근거 사용 중단, 사용 가능한 대상 부재 시 이전 대응의 재사용을 차단한다. A2 대상 지문과 A3 변경안 지문을 각각 확인한다. 근거·판정 이력은 유지한다.
- 후보/A3 관련81개 통과(6.39초). 근거 사용 중단 검사를 보완한 최종 후보 검사22개 통과. 작은 모의에서 동일 의미 재표현의 재사용 제안, 다른 조건의 분리, 정본 update 방지, 대상 수정/사용 중단과 추가 호출 없는 재개를 확인했다.
