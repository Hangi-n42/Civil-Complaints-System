# 회사 지식 P0 — 자료 선정·평가 12건 고정

- 기준: [PRD v1.2](../../00_overview/company_knowledge_prd.md) §5·§12, K1 중 자료 확정과 평가 과제 고정
- 작업일: 2026-09-26
- 범위: 실제 원문 확보·버전/권리 등록·근거 대조·12개 과제 작성과 AI 전문가 페르소나 검수. 제품 구현·성능 측정·패키지 설치는 포함하지 않는다.
- 상태: 자료·평가 과제 v1 고정. 제품 구현·평가 실행 및 K1 전체 완료는 아니다.

## 고정 원칙

- 입력은 문서 버전 최대 20개·CSV 1개 이내다. 동일 원문의 중복 사본은 같은 해시로 식별한다. 자료 내용과 취득/검증 시각을 구분한다.
- 개발 6건·신규 선정 6건은 노출 구분이다. Local 3건·Global 3건·구축/갱신 6건은 별도 기능 유형 구분이다.
- 신규 6건도 이번 설계자와 AI 검토자가 원문·정답을 읽는다. 블라인드·독립 인간 평가라고 부르지 않는다. 이후 프롬프트 튜닝에 사용하면 별도 확인 결과로 주장하지 않는다.
- 정답은 원문 위치·ID·짧은 근거와 개별 기대 판정으로 고정한다. 판정 불가를 허용할 항목과 반드시 답해야 할 항목을 구분한다.
- 미검토·철회·부분 처리 등 애플리케이션 상태 주입은 실제 LH 사건과 구분한다. 원문은 수정하지 않는다.
- 공개 열람, 로컬 파일럿 사용 판단, 원문 재배포 허용을 분리한다. 원문·긴 추출물은 `data/knowledge/pilot_v1/`에 로컬 보존하고 Git에서 제외한다.
- 원문/정답의 오류가 발견되면 이유와 새 버전을 남긴다. 제품 출력에 맞춰 고정된 정답을 조용히 바꾸지 않는다.

## 최종 결과

선정 원문은 **문서 파일 10개 + CSV 1개**, 평가 과제는 **개발 6건 + 신규 6건**, 기능 유형은 **구축·변경 6건 + Local 3건 + Global 3건**이다. 앱 코드는 수정하지 않았다.

### 선정 자료

| 자료 | 파일 수 | 지식 입력 범위·선정 목적 |
|---|---:|---|
| 양산 국민임대 원공고·두 정정 HTML | 3 | 공고 본문과 공식 6단지 메타데이터, 정정 계보 |
| 양산 두 정정 PDF | 2 | 물리 1~6쪽, 단지·모집·자격·선정 기준 및 날짜 정정 |
| 국민임대 임대절차·입주자격·제출서류 HTML | 3 | 각 안내 본문, 일반 규칙·서류·기관·절차 관계 |
| 2026 LH 유관민원 주요 Q&A HWPX | 1 | 표지 기준월 메타데이터 및 임대주택 Q1~Q16 |
| 2015 개정 주택임대규정 시행세칙 PDF | 1 | 물리 1~6쪽, 오래된 규정 현행성·시행일·무근거 주장 구별 |
| 2026-08-10 임대주택 단지 CSV | 1 | 원본 6,217행 보존, 양산 공식 코드 6개 행만 지식 입력 |

공고 PDF와 HTML은 같은 논리 버전의 다른 표현을 포함한다. 문서 파일은 10개이지만 논리 문서 버전은 8개다. 선정 목록은 최대 20문서·CSV 1개 예산 이내다. 동일 정정의 대체 HWPX, 권리 확인용 카탈로그·robots, 미확보 원공고 PDF는 지식 입력에 추가하지 않았다. 문서 전체 사본 보존과 추출 입력 범위를 구분했다.

### 검수·확인 결과

- 제3자 평가설계 AI와 원문 담당 AI가 교차 검수했다. [검토 기록](company_knowledge_pilot_review_2026-09-26.md)에 초안 지적과 후속 판정을 남겼다.
- DEV-05 갱신 조건 근거를 실제 물리 2쪽·인쇄 3쪽으로 추가하고 ‘초과’를 원문의 ‘미충족’으로 수정했다. 2회 미충족 예비입주자 조건과 주택 취득·재계약 횟수 조건을 기대항목에 명시했다.
- NEW-06이 사용하는 Q&A 표지 기준월을 문서 메타데이터 입력 범위에 명시했다.
- 원문 11개 SHA-256, 정확히 12개 과제의 유형 배분, 근거 ID 참조, CSV 6행을 확인했다. 43개 근거 항목 중 인용이 있는 항목은 공백 정규화 후 원문 일치, 구조화 값은 원문 행과 대조했다. 이 검사는 실제 파서·검색·생성 성능 검증을 대신하지 않는다.
- PDF 날짜와 표는 지정 페이지·좌우 면을 대조했고, 모든 페이지를 반복 렌더링하거나 앱 전체 테스트를 실행하지 않았다.

### 산출물과 고정 방식

입력·평가 사용 설명 (`configs/knowledge/pilot_v1/README.md`), 출처 등록부 (`configs/knowledge/pilot_v1/sources.json`), 근거 위치 (`configs/knowledge/pilot_v1/evidence.json`), 고정 해시 (`configs/knowledge/pilot_v1/freeze.json`)를 기준으로 사용한다. 원문은 로컬 `data/knowledge/pilot_v1/raw/`에 보존하고 `.gitignore`로 제외한다. 다른 컴퓨터에서 같은 평가를 재현하려면 공식 취득/허용된 사본의 해시 일치가 필요하다. URL만 같으면 동일 버전이라는 가정은 하지 않는다.

### 남은 한계와 다음 작업

- CSV 외 개별 자료의 운영 사용·재배포 이용허락은 미확인이다. 공개 접근과 이용허락 확인을 동일시하지 않았다. 이번 확정은 로컬 대조용 파일럿 입력 선정이다.
- 원공고 PDF가 없어 첫 정정 이전 대기 인원은 확정하지 않았다. 확보된 두 PDF의 날짜 정정을 전후 비교에 사용한다.
- 신규 6건도 기존 조사 문서의 다른 절에서 선정했고 설계자·AI 검토자가 읽었다. 독립 블라인드 평가, 실제 LH 담당자·인간 전문가 승인으로 표현하지 않는다.
- 안내의 실제 개정일·구 규정 현행성·실시간 공실은 확인되지 않았다. 평가용 가상 승인/누락 상태와 무근거 후보는 실제 LH 사실이 아니다.
- 이 12건은 고정된 대표 과제다. P0의 모든 운영 요구·중간 철회·롤백·장애 복구를 다 확인한 것으로 간주하지 않는다.
- **다음 K1 작업:** 같은 12건에 대한 B0/B1/B2 작업표·측정 구간과 최소 데이터/API 계약을 고정한다. 실제 업무 검토자 및 운영 자료 이용 범위도 구현 성과와 별도로 확인한다.
