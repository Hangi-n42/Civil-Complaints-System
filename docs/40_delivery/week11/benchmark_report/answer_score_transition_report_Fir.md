# rand100 답변 점수 변화 보고서

## 1. 해석 기준

- **첫 답변 점수**: 모델이 처음 생성한 답변에 대해 Civil LLM-Rubric이 산출한 `civil_llm_rubric_initial.score_summary.q0_final`입니다.
- **루브릭 평가 후 답변 점수**: Civil LLM-Rubric 저점 항목을 Prometheus 피드백으로 반영한 뒤 최종 채택된 답변의 `civil_llm_rubric.score_summary.q0_final`입니다.
- **ARES 평가 후 점수**: ARES는 답변을 새로 생성하지 않고, 최종 답변에 대해 context relevance, faithfulness, answer relevance를 진단합니다. 따라서 이 단계는 “답변 변경 후 점수”가 아니라 “최종 답변에 붙은 원인 진단 점수”입니다.
- **ARES LLM judge**는 전체 100건이 아니라 사람 검토 샘플 21건에 대해 재평가한 결과입니다. 전체 100건 ARES는 `ares_lite_scores_mapped.jsonl`의 rule 기반 결과입니다.

- ARES LLM judge sample 21건은 overall 평균 **6.08점**으로 rule 기반보다 높게 나왔습니다. 다만 LLM judge에서도 위험도 분포는 `{"high":20,"medium":1}`로 남아 있어 근거성 문제가 완전히 해소된 것은 아닙니다.

## 8. 결론

- 루브릭/Prometheus 재생성은 평균 Q0를 소폭 올렸지만, 35건은 오히려 Q0가 내려갔습니다. 재생성 채택 조건을 Q0만 보지 말고 citation support, segment coverage, unsupported commitment 같은 품질 신호와 함께 판단해야 합니다.
- ARES rule은 전체적으로 매우 낮게 평가했지만, LLM judge sample에서는 rule보다 완화된 점수가 나왔습니다. 따라서 ARES rule 결과는 “확정 점수”보다 “위험 후보 탐지”로 보고, 중요 case는 LLM judge 또는 사람 검토로 재확인하는 흐름이 적절합니다.
- 최우선 개선 방향은 답변 문체보다 **검색 context와 현재 민원의 의미 일치**, **근거 없는 행정 확약 차단**, **citation이 실제 주장과 맞는지 검증**, **복합 민원 segment 누락 방지**입니다.
