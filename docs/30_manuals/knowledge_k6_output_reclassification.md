## 1. 재분류 기준

| 기호 | 범주 | 판정 기준 |
|---|---|---|
| C | 핵심 사실 오류 | 잘못된 출처·숫자·단위·조건 방향, 없는 원인/범위 단정. 문장의 인용 근거 불일치도 사례에 기록 |
| N | 질문에 필요한 정보 누락 | 질문이 요구한 결론·조건·비교의 필수 설명이 빠짐. 오답을 내놓은 같은 부분을 다시 누락으로 중복 계산하지 않음 |
| S | 부가 정보 누락 | 있으면 도움이 되지만 현재 질문의 결론을 바꾸지 않는 보충 정보. **결함·실패 점수가 아님** |
| P | 표현상 문제 | 중복, 질문 밖 사실 나열, 불필요한 면책, 내부 선택자/좌표 노출. 의미가 달라지면 C/N으로 판정 |

한 출력에 여러 독립적인 문제가 있으면 복수 표기한다. 같은 범주에 문제가 여러 개 있어도 출력 1건으로 집계한다. ‘—’는 이 네 범주에서 확인된 문제가 없다는 뜻이며 일반 성능 인증이 아니다. S는 과거 체크리스트가 요구한 보충항목의 누락을 기록하며, 답변에서 생략한 모든 사실을 나열하지 않는다.

**답변 전체를 읽는다.** `answer`와 화면에 별도로 나오는 `limitations`를 함께 평가한다. 한 문장에서 빠져도 다른 답변 문장에 명시됐으면 전체 누락이 아니다. 근거·관계 경로는 API의 실제 `citations`/`paths`로 확인한다. 다만 `fact_details`에만 있는 사실로 본문의 답변 누락을 보충하지 않는다.

## 3. 무엇이 실제로 좋아졌는가

1. **좁은 질문의 선택과 간결성은 개선됐다.** 동수만 묻는 EXT-01은 A 431자 → B/C 22자·Q 31자. 다른 단지의 두 속성을 묻는 EXT-03은 A 1,178자 → B/C 47자·Q 28자다. 필요한 값/인용을 보존하면서 무관한 속성을 제거했다. 여기서는 A도 값은 맞았으므로 ‘사실 정확성이 올랐다’보다 ‘정확성을 유지하며 선택과 간결성이 개선됐다’가 정확하다.
2. **서류 안내도 핵심 기능은 모두 충족했다.** 문서명·발급기관과 반환 관계 경로가 존재한다. B의 HTML 태그, C의 좌표, Q의 기관 반복은 표현 개선 대상이지 핵심 사실 실패가 아니다. 본문은 A 297자 → B 226자·C 161자·Q 138자로 줄었다.
3. **Q7 정상 질문의 다음 유형 전체 누락은 없었다.** B/C도 앞 문장에 다음 세 범주가 모두 있다. 뒤 목록만 보고 전체 누락으로 판정하면 잘못이다. B/C에 남은 필수 누락은 ‘이전 조건의 일반 범주’이며, Q는 그것까지 최종 목록에 보존했다. Q의 중복 설명은 표현 문제다.
4. **Qwen의 A-5 답변은 출처별 수치 분리가 나아졌다.** B/C와 달리 실제 PDF 985호 주장(a8)을 선택했고 HTML 수치를 PDF에 있다고 쓰지 않았다. 동수·날짜 생략을 이 개선과 상쇄하지 않는다. CSV 범위 설명의 충분성과 HTML 설명/메타데이터 구별은 남은 보완점이다.
5. **Qwen이 역방향 질문을 잘못 긍정한 것은 아니다.** EXAONE B/C의 ‘네’는 핵심 오류다. Qwen은 이를 쓰지 않았지만 확인 불가 판단도 하지 않았다. 잘못된 긍정에서 미응답으로 바뀐 차이는 인정하되 질문 해결로 보지 않는다.

반면 **문맥 묶음 C가 B보다 의미 정확성을 높였다는 증거는 없다.** 이번 EXAONE B/C는 같은 세 질문에서 핵심 오류가 났고 같은 질문에서 필수 누락이 났다. C가 더 짧다는 결과만으로 문맥 구조의 정확성 효과를 주장할 수 없다. Qwen은 B로 시험하지 않았으므로 Qwen 자체의 차이와 특정 구성의 상호작용까지 분리할 수 없다.

## 4. 어디를 먼저 고쳐야 하는가

추가 근거 수집이나 전 항목 강제 출력을 우선할 이유는 확인되지 않았다. 오류에 필요한 숫자·단위·범위·Q7 원문은 이미 입력에 있었다. 저장된 요구 명세와 선택 ID에서 다음 경로가 확인됐다.

| 우선순위 | 확인된 문제/발생 위치 | 좁은 보완 방향 | 이번 분석으로 입증되지 않은 것 |
|---|---|---|---|
