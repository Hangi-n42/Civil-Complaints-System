# A4 저장된 탐색 초안 검수

- 범위: 이슈 #523. 기존 `/knowledge`에 저장된 A2 결과 선택과 A3 변경 검수 연결.
- 기반: main `c8910ea` 확인 후 당시 미병합 A3 PR #530의 검수 커밋 `d1b742e`에서 분기. 2026-10-01에 A3의 main `957c99f` 병합을 확인했다.
- 기존 React 화면·A3 서비스·SQLite 결정을 재사용한다. 새 의존성, 모델 호출, 정본 생성기, 운영 활성화 경로를 추가하지 않는다.

## 실행과 사용

기존 서버/프런트 실행 방법을 사용하고 `KNOWLEDGE_ENABLED=true`로 설정한다. 프런트가 다른 주소의 서버에 연결하면 `NEXT_PUBLIC_API_BASE_URL`을 지정한다.

1. 회사 지식 → 온톨로지 초안 → 저장된 탐색 초안 검수에서 실행을 선택한다.
2. 저장 결과가 있는 종료 실행만 명시적으로 변경안으로 변환한다. `partial`, `failed`, `cancelled` 상태·종료 사유는 유지한다.
3. 후보를 선택하면 고정 자료 버전의 인용·인접 구간·표 문맥을 조회한다. 반례 원문도 별도로 선택할 수 있다. 제목/헤더 복원과 문서 전체의 의미 검토는 구분한다.
4. 의미·정의·범위·예외·변경 이유를 편집하고 결정자와 사유를 입력한다. 종류·참조·근거 구간·양방향 기록 수정은 모델링 상세에서 수행한다.
5. 편집 저장은 미승인, 수정 후 수락/수락은 A3 검토 버전 생성이다. 보류·기각·형식 오류 후보도 편집해 재검토할 수 있다. 운영 활성화는 A5 범위다.
6. 결정 후 후보·이력·preview·검토 버전을 다시 조회한다. `409`는 입력을 보존하며 최신 값 비교와 명시적 revision 선택 후 재검토한다. 다른 변경안이 head를 갱신했다면 새 기준의 실행에서 작성해야 한다.

수동 자료 선택 K3 화면은 별도 선택으로 유지한다. 기존 v1 수동 화면에는 v2 버전을 넣지 않는다.

## 표시와 API 계약

- 기본 질문은 의미·조건·예외·동일 대상 여부. ID·LinkML·JSON Schema·어휘 registry·상속 슬롯은 상세 정보다.
- AI 의견은 A2 원제안 당시 의견이다. 사람 수정 후 재평가로 표시하지 않으며 형식 통과도 의미 정확성으로 표시하지 않는다.
- 계층은 대상 이름과 양방향 지지/반증/판단 불가를 표시한다. 판단 불가는 부정이 아니고 양방향 지지도 자동 병합하지 않는다.
- 같은 종류·표시명의 반복 제안은 화면에서만 묶는다. 개별 ID·상태·근거 유지. 신규·병합·폐기·계층·정의/범위/근거 수정은 개별 결정이다.
- 일괄 수락은 수락 가능한 미검수 `update` 중 기존 근거·조건·의미가 그대로인 표시명 변경만 허용한다. 종류·영향·범위·연결이 다른 선택은 차단한다.
- CQ별 상태는 서버 coverage와 연결 후보/보류 수만 사용한다. 전체 미방문·공백을 특정 CQ에 임의 배정하지 않는다. 간접 영향은 미탐색으로 표시한다.
- `GET /api/v1/knowledge/runs?limit=30&before=<cursor>`: A2 analyze 실행 요약만 반환, 최대 100개·rowid 커서. 전체 모델 출력/원문은 목록에 싣지 않는다.
- `GET /api/v1/knowledge/evidence/{id}?run_id={id}`: 해당 실행의 고정 parse/block만 조회. 다른 scope/실행의 근거는 거절한다. `run_id` 없는 기존 조회 계약은 유지한다.
- 사용 제한된 근거는 원문 조회에서 거절한다. 제한된 주변 블록을 제외하고, 파일 내 제한 자료가 있으면 파생 제목·헤더도 보수적으로 생략하며 사유를 표시한다.
- 인용 span은 서버의 Unicode 코드포인트 기준과 일치한다. 원문/parse 포인터 변경이나 재파싱은 하지 않는다.
- 변환·결정·preview는 기존 A3 API를 사용한다. revision/head와 최종 유효성 판단은 서버가 맡는다.

## 남은 범위

- A5는 검토된 v2 정본과 어휘 registry를 K4/K5/소비자·활성화·재추출에 연결한다. A4 수락은 운영 활성화가 아니다.
- A6 전체 평가, Windows 실기, 12과제·다중 모델 비교, 현업 사람 검수 효과는 미검증이다.
- 실제 저장 묶음에는 수락 가능한 계층·병합·폐기 예제가 없어 해당 UI는 합성 자료로 확인했다. 실제 업무 의미를 시험 목적으로 수락하지 않았다.
